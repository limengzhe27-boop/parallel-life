## 1. 体验与视觉

一句话：拿起另一种人生的手机。

借鉴 Zeta 的窄幅 App、图像优先、紧凑导航与底部操作。本产品仍从用户自己的经历出发；认识阶段底栏建议「聊聊 / 如果 / 我的」，进入世界后由手机桌面承担导航，避免底栏和 Dock 叠两层。

PC / 平板从第一个页面开始采用 Zeta 式居中窄幅 App（建议宽 440–480px，高度占满可用视口）；两侧为近黑背景，不强加厚重金属边框、刘海或假电量。访谈、档案、推荐、资料选择、桌面、应用、导演都在同一手机视口内完成。电脑上的鼠标、键盘正常使用；实际手机上去掉外框，全屏展示。不把现在的网页缩窄塞进边框：每一屏重新安排主次和操作。

建议视觉：照片与生活物件占主角，外部暮色灰蓝；聊天页浅灰白，档案暖白，推荐以场景封面承载，桌面使用照片壁纸和辨识度高的彩色图标。薄玻璃只用于桌面 Dock / 通知，不把所有容器做成蓝色描边卡片。趣味来自翻照片、生活消息、揭开下一张人生和打开应用的反馈，不靠堆渐变、英文口号或夸张特效。

## 2. 逐屏设计与文案

|屏幕|展示与互动|建议文案|
|---|---|---|
|第一次打开|手机内欢迎页；一幅场景画面、一个主按钮，可跳过介绍；已有访谈直接恢复聊天|「如果，那天选了另一条路。」／「从我开始」|
|认识我|熟悉的聊天页；顶部头像和名称；底部输入/照片；不在旁边展示整份档案|「最近，有什么一直放在心上的事？」输入提示「说说最近的你…」|
|我的档案|从聊天顶部打开；本人照片、简短标签、重要人物、往事曲线，逐项编辑|「我的故事」／「记下一件事」／建议待确认：「这像你吗？」|
|选择人生|竖向封面列表或一张主卡加下一张预览；短标题、两行生活片段；不默认展开长文|「这一次，想怎么过？」／「试试这条人生」／「换个方向」|
|方向详情|手机内详情；画面、生活片段，依据/取舍折叠可读；底部主操作固定|「为什么想到它」／「这条路，也有另一面」／「我想改一点」|
|选择资料|手机内分步页面：构想正文、资料、人物照片。选择范围仍明确，不以压缩文案省掉含义|「带上哪些熟悉的人和事？」／「保存这个想法」|
|保存设定|只在真实保存后显示；未生成世界时不可出现假锁屏或假好友消息|「这个想法，记下了。」说明「人生设定已保存，世界还未生成。」|
|生成与进入|接入真实世界创建后显示实际阶段；完成后进入锁屏/桌面|完成前「正在准备这段生活…」；全部完成后才显示「打开这部手机」|
|世界桌面|锁屏时间、照片壁纸、真实通知；消息、相册、日历、便签、朋友圈|通知由实际世界事件提供，不预设所有人都是导演|

以上访谈问题仅为开场语示例；后续内容仍由对话产生。生成的推荐短标题不能通过界面截字改变含义：后续协调生成契约加入展示字段，先保留现有全文并提供详情。场景封面须区分通用插画、用户照片和真实生成结果；图片能力未接通时可以用明确的通用生活插画，不冒充用户的平行照片。

## 3. 文案规则

- 每屏一个主问题、一个主动作。说明放在相关动作旁，详细说明按需展开。
- 第一屏标题建议 12–18 字，按钮通常 2–8 字；生成长标题允许自然换行和详情，不机械裁掉事实。
- 常规界面移除 A DIFFERENT CHAPTER、来源计数看板、重复品牌标语，以及 Worker、版本、快照等实现用语。
- 提示具体说明发生了什么、接下来能做什么。例如「刚才没连上，写好的内容还在」＋「再试一次」。
- 私密资料、照片选择、虚构设定、失败和未完成状态需要清楚表达，不能为沉浸感藏掉。
- 不给用户诊断，不宣称看穿弱点或注定成功；方向须允许讨论与拒绝。
- 文案集中管理，交付包含逐屏文案表，避免各 Agent 各写一套产品语气。
