# 任务报告模板

复制到自己的 docs/task-reports/任务ID.md。占位字段必须填真实值；不要把模板本身当验收证据。主目录任务表存状态和归属，报告存细节。

- 任务 ID：
- Agent ID / 会话标识：
- 角色：
- 工作目录 / 工作树：
- 基线提交：无 Git 时明确写尚无 Git。
- 已完成依赖：
- 允许修改的具体路径：
- 独占资源（端口 / 数据库 / 迁移编号 / 生成额度）：
- 领取时间 / 最后更新时间：

## 当前接续点

- 当前状态：进行中 / 待验收 / 阻塞 / 需返工 / 已完成。
- 已经实现或完成的步骤：
- 当前尚未完成的部分：
- 下一条具体操作：
- 需要协调的公共文件 / 接口：
- 阻塞原因与恢复条件：没有就写无。

## 交付与验证

- 实际修改文件：
- 交付提交 / 文件证据：
- 执行过的检查和结果：
- 真实模型：已验证 / 未验证 / 本任务不涉及。
- 真实数据库：已验证 / 未验证 / 本任务不涉及。
- 浏览器尺寸与交互：已验证 / 未验证 / 本任务不涉及。
- 已知问题、失败样本和未验证范围：
- 是否涉及契约变更、兼容和迁移：
- 不含密钥、私人照片内容或完整访谈。

## 过程记录

按时间追加关键进展，不能用一条“已完成”覆盖失败记录。保留必要接续点即可，不复制完整工具日志。
