## 后续供稿约定

每个新作品使用独立稳定标识，名称可以改，标识和已发布版本不能随之更换。每批供稿新增 `source-v002` 等源版本，不覆盖上一批；记录文件名、字节、SHA256、关联附件、来源日期和已知缺项。创作者修改稿、AI建议稿、经过确认的运行稿分开保留。

一部作品可以包含多个章节和事件；这些不是独立作品，也不是玩家的世界存档。来源版本、编辑修订、正式发布版本及玩家存档是四个不同概念，不能用单一“版本号”代替。

原件长期备份和团队共享位置待按公司流程确定；当前 `.local` 归档是本机副本，不属于 Git 远程备份。每份原件必须能回溯，不能只留 AI 摘要。创作者后台建成后，可迁入受权限保护的原稿库，核验相同摘要后再切换索引。
