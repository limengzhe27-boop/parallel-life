# 已确认的信息与功能架构

2026-09-22，用户明确要求按此结构开发。本文优先于旧版三栏/三标签导航方案。三个空间是先后进入的体验，不是底部三个 Tab。

## 认识我的空间

初次进入可填出生信息，也可直接聊天。个人 Agent 围绕最近烦恼、愿望、经历和选择交流；人生提案在该对话中讨论。我的档案按需打开，包含基础信息/照片、兴趣与自述偏好、重要人物、事件与选择。出生资料不会自动推出已确认性格或真实命运。

## 人生创建流程

提案详情 → 调整身份与情境 → 确认虚构起点和带入资料 → 创建进度/失败恢复。用户先确认再保存；未实现世界生成时，保存设定不显示“世界已生成”或假进度。

## 平行世界手机

桌面包含壁纸、故事时间和通知。消息含联系人/聊天；日历区分邀请/约定/已发生；相册含照片/作品/事件回忆；便签支持私人记录及主动分享。人生管理是固定辅助入口，含导演、身份与经历、时间/暂停、返回现实/切换人生、存档/账号/删除。四个 App 共用世界事实，不单独造剧情。

## 本轮实施顺序

1. U-03/U-04/U-05：撤销三标签，轻量入口、个人对话内提案、按需档案、独立创建详情与保存恢复。
2. H-01/U-06：保留另一 Agent 工作树成果，待提交交付后由集成人统一验收；不覆盖其进行中的文件。
3. D-03/D-05 和 W/H 系列：真实创建世界、角色回合和四 App 的事件联动。持续管理能力由 L/G 系列接续。

本轮不把后续未接入的功能画成可用按钮，不把通用设计素材冒充个人生成照片。原“聊聊 / 如果 / 我的”导航已经废止；旧设计文件中相反描述以本文为准。
