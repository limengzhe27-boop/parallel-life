# 已确认的信息与功能架构

2026-09-22，以用户最新纠正为准：App 保留固定底部「聊聊 / 如果 / 我的」三个导航。此前将功能层级误解为取消底栏，现已纠正。

## 左侧：聊聊

与个人 Agent 对话，讨论最近烦恼、愿望、重要经历和人生选择；可讨论并调整人生提案。首次可填出生信息或直接开始。聊天中的信息由 Agent 整理到「我的」，推测以待确认条目呈现，用户可以修改。生日不会直接推出已确认性格或命运。

## 中间：如果

集中展示不同人生分支、保存的设定及新的提案。已生成的世界点击进入对应的平行世界手机；未生成的设定明确显示状态，不能伪装为可进入的世界。创建流程：提案详情 → 调整身份/情境 → 确认虚构起点及带入资料 → 创建进度/失败恢复。

当前保存设定和提案是真实数据，世界生成接口尚未接通，卡片暂时打开设定详情。后续 D-03/D-05 接通后从这里进入对应世界，保留多人生列表。

## 右侧：我的

一级页面，包含基础信息和照片、兴趣/性格自述/偏好、重要人物、重要事件和选择。个人对话与这里使用同一份真实档案。聊天整理的内容可确认、手动修正和补充；不把虚构世界的经历自动写入现实档案。切换聊聊和我的时保留聊天草稿。

## 进入世界后：平行世界手机

壁纸、故事时间和通知组成桌面。消息包含联系人与聊天；日历区分邀请、约定和已发生；相册包含照片、作品和事件回忆；便签支持私人记录和主动分享。人生管理为固定入口，包含导演、身份与经历、时间/暂停、返回现实/切换人生、存档/账号/删除。

三导航属于外层 App，世界手机独立承载沉浸体验，并有返回外层和切换人生的路径。四个应用共用世界事实；角色收到裁剪后的可见信息，不接收完整现实私人访谈。
