# 信息架构：当前基线与重构目标

更新：2026-09-28。固定“聊聊／分支／我的”，用户进入人生后使用独立的平行世界手机。目标说明见 [EXPERIENCE_REBUILD.md](EXPERIENCE_REBUILD.md)，任务状态以 [DEVELOPMENT.md](DEVELOPMENT.md) 为准。以下目标尚未全部实现。

## 当前可见入口

- 聊聊：个人Agent对话，照片上传，分支操作入口。
- 分支：已有世界、保存的设定与新的方向；可进入锁屏。
- 我的：照片、候选资料、基础资料、兴趣/性格/愿望、重要人物、人生经历。目前分类与历史资料映射不完整。
- 世界手机：锁屏、桌面、联系人/私聊、相册、日历、便签与辅助管理；部分朋友圈内容为模板，真实生图未实现，不计为正式完成。

无独立欢迎页或首填姓名生日表单；可直接聊天。无需为了完成资料表才开始体验。

## 重构后的外层

### 聊聊：理解与共同构思

主界面只有顶栏、对话和输入。向导根据已有信息选择倾听、问一个关键未知、回读理解或提出人生草案。一次对话完成后，资料与草案变化应同步可见，不能等用户手动刷新。

草案内明确：想体验的身份、分岔点、当前生活情境、重要关系、基调。用户可随时改、继续聊或暂不进入。愿望不是事实，故事草案不是已经存在的世界。

### 分支：选择或继续生活

已有分支等权展示；卡片给身份、时间/进展、最近变化和继续入口，同名分支也能分辨。新的草案独立成组，不在已有人生列表下平铺所有长设定。

所有创建入口共用：具体草案 → 调整起点及带入范围 → 创建进度/恢复 → 锁屏。选择绑定草案版本，不自动选择后生成的第一条方向；照片不默认因已上传就带入。

### 我的：看得懂、改得动的真实资料

当前的我（小头像、称呼、已知处境） → 我在意的（兴趣/偏好/愿望） → 走过的路（经历/选择） → 重要的人 → 照片与基本资料。

“新整理的内容”按需打开，显示变化和来源。摘要从同一份有来源的记录构成，修改/遗忘后同步更新。所有已保存类别都有定位和编辑入口，历史条目先映射不丢弃；推断/有歧义/冲突需核对，不把生日推成性格。

## 重构后的世界手机

- 锁屏：世界时间、壁纸、相关通知；点击进入对应事情。
- 桌面：应用与简短生活入口；大段设定和管理操作收进次级页。
- 消息：人物来信、自然私聊、引用/邀请/照片附件；群聊为待验证方向，不是已上线承诺。
- 相册：真实素材与回忆，明确生成状态、人物与事件关联；无内容时不显示无意义筛选。
- 日历：待回复邀请、已确认约定、活动结果；与聊天同一状态，不把接受等同已参加。
- 便签：用户私人记录和来源明确的生活资料；不捏造用户已经写过的内容。
- 人生管理：身份、导演、暂停/节奏、切换人生、账号/数据；未实现入口不得伪装成功。

主动反馈来自已成立事件：角色兑现、邀请变化、素材完成或其他相关进展。所有应用消费同一份已提交结果，不靠标题猜照片、不靠定时器随机发消息。其他NPC介入先验证有因果的另一路消息，再考虑介绍/群聊。

## 页面与状态交付矩阵

首批统一审阅：聊聊空态/对话/草案；我的空态/资料/变更；分支空态/多人生/创建；锁屏/桌面；消息列表/私聊/图片/邀请；相册空态/生成/详情；日历/邀请；便签；管理。

每屏覆盖正常、加载、失败、无内容、长内容、返回、键盘、窄屏和PC。图标、字体、间距、控件反馈、导航和素材来源一致。真实场景内容用于验收，不仅设计精美静态样板。
