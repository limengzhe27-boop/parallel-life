# 首次打开分支手机：接手一段已经发生的生活

2026-10-09，用户新增要求：分支建立后不能所有内容从零开始，要像见到一部已经使用过的手机。与早期“捡到平行世界自己的手机”的方向一致。此文为新增产品规格；BOOT-01尚未领取实现，不表示本批已上线。

## 已有实现与实际缺口

已核对世界开场生成与保存：目前会生成人物、少量开场私聊和便签，开场消息用分钟间隔放在创建时刻之前，保存到初始基线。不是完全空白。但模型契约只有1—4条开场消息和1—5条便签，创建时日程为空；人物内部设定与转述关系不等于已有可见生活历史；真实素材需有实际引用，不能用文本声称照片已经生成。

因此“有几条未读消息”不等于“接手已生活了一段时间的身份”。没有持久前史、相互一致的过去约定和现实可用入口时，用户仍会像刚注册了新手机。新增前史必须补创建和世界运行的共同基线，不能仅填满页面或把当前生成时间改成几天前。

## 要交给玩家什么

|手机内容|让玩家理解什么|如何影响后续|
|---|---|---|
|联系人与关系|谁已经与这个身份相识，谁尚未出场|旧相识可自然联系，未知人物仍需实际介绍；不公开内部秘密|
|以前的聊天|对方的口气、正在往来的事、曾经留下的话题|NPC回应时能承接，未了结的约定可影响当下|
|日历|已经发生的活动、即将到来的约或待回应邀请|时间、状态、地点、参与者和聊天相符；不将邀请直接当玩家已接受|
|相册|实际可查看的素材、所带入人物或已有作品|与聊天中的同一素材关联；缺图时不假装有图|
|备忘录|这个身份已知的资源、生活琐事、还惦记的事|能成为眼下行动依据，不能泄露NPC幕后动机或未来结局|
|锁屏|现在有什么值得打开的事|少量未读吸引进入；旧已读历史不会全部冒作刚发的通知|

首屏不罗列完整人物小传和剧本。玩家从手机里逐步拼出过去，带着问题开始行动。完整预设剧本由相关内容人员提供的方向继续保留，不在此决定其主线约束或公开发布方式。

## 过去 / 现在 / 后续

1. 创建时确定这条人生的身份、时间、资源和已发生背景，形成一个固定的虚构起点。
2. 生成与这一起点一致的有限生活前史：以前的来信、已知交往、可用记录，以及尚未解决的一两件事。不是先模拟数月所有NPC活动。
3. “现在”有一件可以回应、查看或介入的事，也允许自由探索与暂时不理。历史材料为它提供依据，不是人人同一刻群发开场白。
4. 用户接管后，自己的新发言和行动完全由真实输入决定。导演和NPC依据前史以及此后的实际选择继续发展，不能为了新剧情每轮改写过去。
5. 离开再回来时，由既有时间/回访机制在同一世界中有界推进，旧前史与新事件可区分；初始内容不每次刷新重生成。

## 一个示例（讨论样例，未实现）

用户选择导演身份。手机里有几天前制片人关于场地的来信、昨天摄影师确认的器材信息、明天的一项尚待回应的试拍邀请，以及“预算剩余，场地只留到周五”的备忘录。现在制片人发来“场地那边在催了，今晚能回个话吗？”

玩家可以联系不同人、查看邀请或采取自己的办法。若后续回应场地问题，NPC必须知道那些已确定的前史；若预算实际上没有确定，则不能为制造困难临时造一个旧欠款。示例中没有替玩家编当前答复，没有保证必须完成试拍，也没有确定未来拿奖。

## 重要边界

- 分支前史是虚构设定，不写回现实“我的”，不把用户私人访谈开放给NPC。
- 体验他人提供的剧本时，继承的是该设定可授权演绎的虚构前史，不是作者私人访谈或其他玩家的聊天、操作和素材。各玩家自己的世界仍独立。
- 初始历史是世界创建的来源；“设定中的过去”与玩家接管后的真实输入记录有区别。不能把模型生成的历史气泡伪装成玩家本人曾操作过产品。
- 首版可先使用NPC过往来信和已知背景，不急于生成主角历史发言。若以后需要完整双向旧聊天，必须先确定虚构前史的展示、来源和记忆规则，不能绕过“不得替当前玩家发言”。
- 历史事实、联系人知情范围、日历状态、备忘录和相册应共同来源于同一创建基线。配角私有动机不可通过便签或联系人卡泄露。
- 历史约定可以在身份起点内成立；当前的新邀请不能替玩家自动接受；未来重大选择不预先完成。
- 时间必须按故事时间表示，历史早于接管时刻，日历、消息与记录互相对应，不在前端随机造日期。设定可能不在当代，不能把真实手机今天的日期混为过去剧本时间。
- 只有真实上传且已选带入、明确项目素材或真实生成成功的图片才能显示；通用素材注明来源，成本允许时再按需生成，不用伪图补满相册。
- 相同创建命令重复、页面刷新或恢复不会新增历史。失败不能留下半套人物、历史、日程；原有世界和不可变初始基线不被静默覆盖。

## 推进与验收

先完成当前聊天引导/照片归属与用途联合修复，再由唯一集成人冻结BOOT-01准确范围与兼容契约。复用已有开场、事件/投影、记忆和初始快照，不新建平行的剧情存储或页面假数据。

至少验证两种不同身份：首次进入已有内容与当前事情有因果；NPC能回答旧约定而不全知；历史日历与消息一致；照片只有真实素材；刷新/重进仍是同一前史；用户不回应时不会代其完成；新行为能改变后续；跨世界/账号与现实隔离；旧世界兼容。真实模型、PG、双端、READY及公网才算交付。
