## 用户确认的方向

- 底部固定「聊聊 / 分支 / 我的」。聊天只有顶栏、对话、输入与底栏，不放宣传语，不在首次进入时展示个人信息表单。资料由 Agent 按需询问。
- 所有分支同尺寸、同层级。不突出「最近体验」，不按分支数量切换主卡/小卡布局。
- 390×844 设计稿中，分支入口统一为 350×82，间隔12；缩略图58×62。显示身份名称、一行进展，右侧未读数字或箭头。
- 三分支、六分支使用相同组件、位置和字号。更多条目在内容区滚动，顶栏、筛选及底栏固定；小屏使用可用高度，不将844作为运行时固定高度。
- 按最近进入排序，阅读中不因后台消息跳动；返回保留列表位置。点击分支进入对应世界手机。
- 右上新增回到个人 Agent 讨论新的可能。全部/未读/已归档用于筛选；归档可恢复。

## 交付与边界

Figma 包含聊聊、三条分支、六条分支、我的四屏可编辑文字与矢量图层。统一深色背景与暖杏色强调，封面保持同样大小。缩略图是示意插画，人物身份、进展和未读数均为样例，不是生成结果。未制作完整点击原型，未实现筛选或归档接口。

通过浏览器在 Figma 实际检查四屏排版，截图见 figma-mobile-v4.png。仅设计和文档变更，无业务代码或数据库变更，因此未重复执行构建及业务测试。后续实施须验证手机、PC、短屏、长标题与空列表。
