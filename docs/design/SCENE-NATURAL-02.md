# 现场叙事与人物反应 · SCENE-NATURAL-02

沿用已批准的 DESIGN.md 现场舞台/iPhone窄屏/L1。用户2026-10-14反馈优先：当面互动应有空间、动作、气氛与承接，避免聊天式问答及前后矛盾。

- 开场：呈现实际地点的环境底色一次。随后环境没有新变化可不新增环境段；变化必须来自真实生成并校验保存的现场回合。
- 人物反应：人物独立提出自己的可观察微动作及台词。微动作在台词前作淡色叙事；无动作可省略。不能借微动作生成玩家行为、重大成果或结构化交付信用。
- 普通问话：导演仅处理当下玩家发声、位置和环境，不能预先判定人物“不回应/尚未回答”。台词承接当前问句、已知关系和此前现场，避免客服式“给我一个回复”及反问原问题。
- 展示：环境与可观察动作使用无头像的叙事段；人物对白保头像姓名但减少卡片感；玩家原文保留。时间/地点不因每个结果重复同一行，信息从实际已保存记录读取。
- 一致性：同轮有实际对白，不能保存无人回应结论。各角色只接收自己的可见事实/经历；未知结果不自动重付，不修改已存旧台词。
- 验收：以1个普通小店/1名人物，开场→“有人吗”→“你不是要和我吃饭吗”实际多轮，核环境变化、微动作、台词和知情边界；原结构化维修/交付测试仍须过。390长短屏/1440，真实PG、check/build、READY与公网实测。

普通已在场问句可直接发声并由人物独立回应，不先要求导演裁定问句；原文保存，无事项成果。正式步骤/实际操作仍走导演与独立人物的完整校验。人物上下文显式区分当前事实、玩家发言与过去本人/其他人的发言，普通闲聊限制最近现场轮，完整记录仍可查阅。
