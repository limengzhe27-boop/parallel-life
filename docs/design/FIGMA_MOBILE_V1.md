# 如果 · Figma 手机视觉稿 V1

设计文件：https://www.figma.com/design/yXxv4Z4HNygYWReyb6FYlD

2026-09-22：按用户要求使用 Figma MCP 创建，并在用户登录后通过浏览器完成补充及视觉检查。此稿为待用户审阅的视觉提案，尚未应用到产品代码或线上版本，不替代现有功能任务。

四个 390×844 画板：聊聊（3:2）、如果（3:3）、我的（3:4）、世界手机（3:5）。深墨底、暖白字、珊瑚色主操作，沿用 Noto Sans SC / Noto Serif SC。前三屏保留聊聊／如果／我的底部导航；世界手机展示消息、日历、相册、便签和独立人生管理入口。

聊天首屏选填称呼和生日；档案页展示待确认信息。摄影师、朋友来信、约定及个人资料均是设计示例，不表示真实生成或持久化已实现。照片使用已有项目素材 public/art/first-window.webp，不表示已完成人物一致性生成。

浏览器确认图片实际可见，文字无重叠，三屏底栏位置一致；为封面加 42% 黑色遮罩提高可读性。世界手机下半屏通过 Figma 的 Place image 导入 SVG，已确认拆为文字、矢量和分组，仍可编辑。它与其他自动布局内容的实现方式不同，开发时需按响应式组件实现。

预览图：figma-mobile-v1.png。尚未制作可点击原型连线、完整组件状态或键盘展开稿；整体视觉需用户审阅后再落地，不把四屏视觉稿标成完整产品验收。
