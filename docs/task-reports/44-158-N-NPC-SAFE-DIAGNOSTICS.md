NPC 文字调用失败时，原角色模型路由只输出一条固定事件记录。仅当值符合本地白名单或明确数值范围时记录 `code`、`stage`、`httpStatus`、`durationMs`、`responseOutcome`；未知值直接省略。记录不读取或序列化错误对象、模型输入、响应正文、请求头、模型名、用户标识、密钥、`message` 或 `stack`。记录器自身失败也不遮蔽原错误。

原模型错误对象原样抛出；不增加调用、重试、回退或更换模型。非 NPC 调用与流式调用行为保持原样。这样可在下次真实故障时区分网关明确拒绝、请求阶段不明与耗时，但不会凭这条记录认定已产生图片或自动重新付费。

验证：`tests/role-text-model.test.ts` 4/4 与 `npm run typecheck` 通过，覆盖安全字段、敏感字段过滤、原错误身份、无回退、记录器自身故障与非 NPC 隔离。本任务不调用模型、不访问生产、不修改 SQL。
