# 任务交付报告：L-04 时间锚点、暂停/倍速/跳下一事件、离线分块摘要；关键选择停下，多端/重复恢复不重复推进

## 一、任务背景与核心目标

在《人生剧本》的时间管理与生活流转架构（对应 `PRODUCT.md` §10、`docs/AGENT_ARCHITECTURE.md` 与 `docs/DEVELOPMENT.md`）中，时间流转遵循现实映射与离线聚合规则：
1. **时间锚点 (Story Time Anchor)**：
   - 依赖 `parallel_life.world_clock` 持久化 `story_now` 与现实物理对齐锚点 `last_tick_at`；
   - 只读手机界面的投影通过纯函数 `projectStoryTime(clock, realNow)` 实时计算，不无端生成空洞虚构消息。
2. **暂停与倍速 (Pause & Speed Controls)**：
   - 支持玩家通过时钟控制接口（`PUT /api/v1/worlds/:id/clock`）自由暂停人生、恢复流转，或设定倍速（依法制约束在 0～60 范围，默认浏览 12x、对话 1x、离线 1:1）；
   - 暂停状态在底层事务原子记录，防止离线或后台无端扣费或虚耗剧情。
3. **跳下一事件 (Skip to Next Event / Wait)**：
   - 通过 `POST /api/v1/worlds/:id/clock/wait` 与 `PostgresStoryWaitRepository` 提供确定性的“等待/快进”：
   - 智能识别最近的约定（`next_appointment`）、清晨（`morning`）、关键选择或剧情边界，在到达事件节点或早 10 分钟边界前精确停下，绝不越界。
   - 等待具有严格的事件幂等性：基于 `story_wait_receipts` 防止跨客户端或同一指令重复快进。
4. **离线分块摘要 (Offline Chunked Summaries)**：
   - 玩家长时间离开后重新进入，时钟跳跃至现实流逝时间；
   - 调度器通过 `advanceWorld` 约束最多执行 `MAX_BEATS_PER_ADVANCE`（3 拍），其余流逝时间自动折叠折算并聚合成精炼的离线摘要（`summary`，如“你离开的这段时间里，世界照常运转了大约 X 小时”），落库于时钟元数据，绝不无端虚构假事件。
5. **关键选择停下与多端/重复恢复不重复推进**：
   - 遇到未完结玩家抉择或待答复约定，选人与议程机制优先保留焦点，停下等待玩家回应；
   - 通过基于世界粒度的排他性建议锁 `withAdvanceLock`、`world_clock_activity` 多端租约、以及 `world_director_attempts` 状态记录，保障故障重试、重复恢复或多设备并发时，已提交的回合不再重复扣费或重复派发助手消息。

## 二、问题诊断与修复

### 1. 发现的问题与成因分析
在对既有时间时钟集成测试 `tests/integration/world-clock.test.ts` 进行回归时，发现 3 处用例失败：
1. **用例 1（缺勤步进折叠与拍数）失败**：
   - `advanceWorld` 读取时钟时调用 `deps.clock.read(session.userId, worldId)`，未传入测试虚拟时间 `deps.now()`，导致 `read` 内部的 `realNow` 默认取系统的当前时间戳 `new Date()`。
   - 当测试设定的历史剧情时间早于系统当前时间时，计算流逝的物理时间变为非正数（`elapsedReal <= 0`），导致生成的节拍数组为空，实际流逝节拍被误判为 0。
2. **用例 2（导演重试与并发锁）失败**：
   - 同理，并发推进因为物理时间倒退而直接提早以 fulfilled 返回 0 拍，未能触发模型调用异常路径。
3. **用例 3（玩家反馈在冷却期内优先投递）失败**：
   - 测试用例模拟 1:1 速度，但世界初始化未显式写入初始时钟锚点，导致时钟读取回落到 `DEFAULT_SPEED = 12`，在步进 30 分钟时故事时间跳跃 6 小时至 `06:00`，后续玩家在 `00:35` 回复时触发 reducer 的防时光倒流保护 `World time cannot run backwards`。
4. **`story-wait.test.ts` 端口适配**：
   - 依赖本地数据库环境端口时，硬编码默认 55570，未回落至 `cfg.port`。

### 2. 精确修复方案
1. **`src/modules/world/application/ports.ts`**：
   - 扩展契约 `ClockStore.read(ownerId: string, worldId: string, realNow?: string)`，支持传入显式真实时间基准。
2. **`src/modules/world/application/advance-world.ts`**：
   - 将 `deps.clock.read(session.userId, worldId)` 显式传参 `deps.now()`，保证步进逻辑在任意环境（包括长程测试、回放与多端模拟）下的时间计算精确对齐。
3. **`tests/integration/story-wait.test.ts`**：
   - 端口回退逻辑由固定 55570 优化为 `process.env.STORY_WAIT_TEST_PORT ?? String(cfg.port)`。
4. **`tests/integration/world-clock.test.ts`**：
   - 针对各测试阶段的人生初始化，显式建立 1:1 速度基线锚点（`speed: 1, lastTickAt: start`），确保与测试设计规范中的 1:1 无人值守时间流逝严格吻合。
