## 二、手机端接线方案（下一轮可直接执行）

目标：把已在 API 层完成的四项能力接到手机上。**每个能力都是"只读 + 一个写动作"，不引入新的业务规则。**

| 界面 | 读取 | 写入 | 落点建议 |
|---|---|---|---|
| 时间控件 | `GET /worlds/:id/clock`（故事时间/速度/暂停/被折叠拍数/离线摘要） | `POST /worlds/:id/clock` `{paused}` / `{speed}`；`POST /worlds/:id/advance` | 锁屏或"设置"里的「时间」段；摘要在时钟行下方一行小字 |
| 导演面板 | `GET /worlds/:id/direction` | `POST /worlds/:id/direction`（`preview: true` 先看影响，再 `false` 应用；`move: 'past'` 会被 422 拒绝并提示建分支） | 与时间控件同页：「主题/节奏/聚焦谁」三行表单 + "先看影响"按钮 |
| 记忆界面 | `GET /memory/records?scopeType=character&scopeId=<角色>` | `POST /memory/records`（`correct` / `forget`） | 消息页角色菜单里的「TA 记得的事」；纠正/遗忘各一个确认 |
| 索图结果 | `GET /worlds/:id`（相册投影） | — | 相册应用；媒体未接入时**如实显示失败**，不显示占位假图 |

接线注意（与并发执行者协作）：
1. `src/features/phone/**` 是并发改造区，**动之前先 `git status` 确认无在途改动**，并只改最小的文件集（新增一个 `apps/director.tsx` + 在应用索引注册一行）。
2. 手机契约 `PhoneAppsData` 若要加字段（例如 clock 摘要），属于**公共契约变更**：必须同时补全所有构造点（含测试夹具）并跑 `npm run verify`，否则整仓无法编译——这在过去 24 小时已发生两次。
3. 失败与离线：三个写动作都要沿用现有"发送中/失败可重试"的诚实语义，不允许乐观成功。
