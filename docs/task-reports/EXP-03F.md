# EXP-03F · 「我的」资料与访谈写入收敛

2026-09-28 · 主目录 · codex-main-exp03f

## 问题与行为

旧访谈留下多条独立 identity 句，和结构化「个人资料」同时显示为「当前的我」；生日只说年份时曾被存成虚构的 1 月 1 日。确认前的冲突值还可能进入访谈上下文、分支推荐或建世界资料选择。

现在「我的」只用一份结构化基本资料；旧身份句留在折叠的待整理区域。存在不同生日时不展示一个伪确定值，资料表单展开并要求用户核对；选定后旧散落生日句被标为 rejected，而不是作为第二份当前资料。生日按年、月、日原有精度存储。分支推荐、草案和旧 Seed 选择只读取可信的单一资料；冲突生日从提供给 Agent 的上下文中移除。

访谈两种执行路径使用同一规则：基本资料只从用户明确自述中抽取；模型建议的其他资料若不是原话中可定位的本人陈述，先作为 suggested 候选；冲突生日也只作候选，确认后才写入。身份类平铺事实被拦住，已拒绝资料、假设和临时噪声不直接写入。
