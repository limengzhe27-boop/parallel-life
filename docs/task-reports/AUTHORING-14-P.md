## 实施范围

- 人物页默认呈现联系人聊天预览，真实草稿消息按联系人和时间排序，玩家消息与人物消息左右区分；旧消息缺少发送方时按原人物消息兼容。
- 可点击姓名/头像查看公开介绍，或点击朋友圈查看真实草稿中的开场动态；已有素材采用原 `publisherArtUrl`，无图片采用姓名首字，未造聊天、动态、未读数、点赞评论或生成图。
- 私有五模块采用人生背景、人格特质、动机与价值观、行为模式、关系模型。独立公开介绍可编辑。每模块 4000 字/介绍 1600 字，与公共协议一致，原文无需拆成大量字段。
- 五模块通过原草稿 `onChange` 保存；只更改所选人物的一个字段，原有 privatePersona、publicCard 其他字段、原头像、其他人、手机内容和扩展不被覆盖。
- 旧身份/头像/人格/知情编辑折叠保留；原编辑保存接口及删除保护不移除。删除确认新增朋友圈引用中文提示，实际引用保护由 root 补共享 editor helper。
- 已认识人物仅呈现真实草稿记录；未认识人物保持空聊天/朋友圈。未来内容、损坏日期和未知发送方不冒充开场历史；重复人物 key 不选择其中一个。
- 手机预览的公开投影只读取明确公开姓名/身份/介绍/头像及本人消息/动态，不将五模块、幕后人格、世界暗线、别人的对话混入预览。
