# 44-167 自拍拍摄视角修复（子任务）

负责人：root/selfie_prompt。集成人：root。基线 e870098f；独立工作树 selfie-prompt167，分支 codex/selfie-prompt167。

## 根因与范围

原 MediaPromptBuilder 对所有图片一律追加 50mm portrait lens at eye level，默认又是 Kodak 电影摄影风格。即使已授权工具描述写了“自拍”，最终提示词也会把镜头带回外部摄影师的肖像构图。原 handler 将持久请求 doc.prompt 原样传入 sceneDescription；此路径没有丢掉自拍文本。

修改仅涉及媒体 domain 的 prompt-builder/types、聚焦测试与本报告，不改世界内核、授权、请求创建、任务重试、素材持久化或生产数据。

## 行为

- 明确自拍描述：前置手机镜头、本人伸臂拍摄、臂长距离、轻微俯角、自然广角、脸和肩接近镜头，不显示拍摄手机本体；不再附加 50mm 外部肖像构图。
- 明确对镜自拍：镜中本人手持手机、可信的反射和握持，允许原有半身等构图。
- 普通 portrait 不自动改成自拍；明确“不是自拍”保留外部拍摄。
- 可选 captureMode 支持调用方显式指定；既有请求通过 sceneDescription 中明确自拍措辞兼容。它只决定镜头，不会据此授权或启动生成。
- 参考素材只提供身份，自拍明确要求重建镜头，不照搬参考图的姿态、背景和取景。
- 提示词规则版本提升为 1.1.0。

## 验证与限制

6 项聚焦测试通过：普通图片、视频兼容、前摄自拍、镜面自拍、普通/非自拍、显式模式优先。未调用真实图片模型，不以提示词通过等同于最终图像质量通过；由集成人在原聊天链路验证生成图的实际视角。

尚需集成人确保 NPC 工具 sceneDescription 明确保留用户的自拍拍摄意图；本子任务不基于玩家词语直接触发图片，不把所有人像强制自拍。
