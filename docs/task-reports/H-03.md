## 接入示例与契约补充

```tsx
<PhoneAppsProvider worldId={world.id} data={phoneData} actions={phoneActions}
  loading={refreshing} loadError={safeError} onReload={reload}
  commandResults={commandResults}>
  <PhoneShell {...shellProps} renderApp={context => <PhoneAppView {...context} />} />
</PhoneAppsProvider>
```

从 `src/features/phone/apps/index.tsx` 导入两个组件；展示类型统一从 `apps/types.ts` 导出。Provider须位于PhoneShell外，不能放进每次导航都会卸载的renderApp里。worldId必须真实唯一；切换人生重置本地草稿，不把本地草稿当存档。正文纯文本；adapter只传人物可见的摘要，不能传完整私人访谈。

同正文的网络失败/UNKNOWN重试复用ID；正文更改产生新ID；明确failed终态之后的新尝试产生新ID，避免旧终态污染新的accepted。任务专用重试映射由adapter负责。多次提交防重入，终态仅清理对应且未修改的草稿。
