# RETURN-BRIEFING-63：回访补演时间分布与出戏话术收口（本地）

## 目标

- 离开 ≥3 分钟后回来，补演消息落在离开区间内，而不是全部挤在返回瞬间。
- 醒来后的第一条消息必须是能直接发给玩家的话，不是「我决定/我还在等/先不打扰」这类自我汇报。
- 在干净世界上真实浏览器走通：离开 → 补演 → 锁屏 → 进入会话 → 继续聊。
- 不做 Vercel/生产。

## 改动

- `src/modules/world/domain/return-briefing.ts`
  - 未暂停（离开 3–10 分钟）的世界，时钟在离开期间已按真实时间投影；窗口改为 `[返回时刻 - 离开时长, 返回时刻]`，补演消息回填这段已经过去的区间。
  - 暂停的世界仍向前模拟 `[冻结时刻, 冻结时刻 + 离开时长]`。
- `src/modules/world/infrastructure/clock-activity-repository.ts`
  - 补演窗口以「最后已提交事件」为下界，且始终保证 `storyFrom < storyUntil`（至少 60 秒）。
  - pending 补演把时钟冻结在 `storyFrom`，每个 beat 用 `GREATEST` 向前推进；不再被返回瞬间的投影覆盖。
- `src/modules/world/infrastructure/npc-model-protocol.ts`
  - wake 气泡过滤新增「我决定/我打算/我准备/我还在等/先不打扰/还没有新回应/主动联系你/再考虑下一步」等自我汇报模式；带细节的 messaging-meta 直接丢弃，短句「我决定今晚不去了。」仍保留。
- 测试：`tests/return-briefing.test.ts` 增加 4 分钟非暂停窗口用例；`tests/npc-model-protocol.test.ts` 增加真实漏出的两条话术。
