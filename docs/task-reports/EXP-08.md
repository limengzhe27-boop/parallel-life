# EXP-08 · 分支入口与世界消息时间

状态：待验收（代码、真实库与双端已通过；等待公网发布）；负责人 codex-main-exp08-20260928；基线 f1ba05d。

目标：清理已建分支中的无效修改入口；把世界时钟投影、开场时间、用户发信和 NPC 回复时间连成一条有来源的时间线。旧世界原始消息不改写。

已实现：

- 分支列表以已创建的人生和未完成草案为主；已创建方向不再出现“构想新的分支”与不可用的修改按钮。只有尚未采纳的新方向或进行中的推演，才显示待决定的提案。新的分支仍可从顶部「+」进入对话发起。已进入人生的未来走向由手机里的导演入口调整，不声称可以改写已发生的剧情。
- 老世界如果多条开场通知都被旧版本盖上完全相同的起点时间，只在读取时为这批虚构开场通知重建有先后的时间；不可变原始快照及真实用户消息不改。
- 手机读取默认按真实时间 1:1 投影世界时间；暂停与倍速保持生效。用户发信与 NPC 实际回复分别取请求前和回复完成时的世界时间，随同事件、消息、世界状态及世界时钟在同一个事务落地。重进手机不会把历史消息都改为当下时间。
- 本地合成旧分支暴露了无任务关联的旧世界列表读取 503；修复关联表的同名时间列覆盖，并补真实库回归。

验证：`npm run check`：211/211；`npm run test:db`：31/31；`npm run build` 通过。生产数据库 28/28 迁移校验和一致，本次无新增迁移。Ego Lite 本地 390px/1440px 页面无横向溢出；合成旧分支锁屏时刻 06:55，历史通知分别 06:16、06:39、06:46，分支页不出现无效修改入口。未在生产创建测试世界；公网验收待发布。
