## 实现

- 原实现按 world 锁全部 agent_attempts 并读取每条 response，之后才用 JS 找当前 task。
- 改成原 task 输入事件 → 原 receipt → 轻量 id/actor/command 候选 → 仅目标 attempt 精确 FOR UPDATE。轻量候选仍验证 nativeAgentCommandId，不新增 SQL hash 算法或业务字段。
- 删除已有 attempt 恢复里的独立 world.version 相等门槛；复用 resolveAgentCommitVersion，提交和恢复遵循同一依赖证据规则。保留原 snapshot/receipt/attempt 版本，不改写模型基线。
- 原 actor revision、engine epoch、群/现场成员权限、原输入来源、token fencing、回执幂等和 unknown 防复购均保留。
- 无 attempt 的零发送分支未修改，按 root 分工由 R1/root 统一接线。
