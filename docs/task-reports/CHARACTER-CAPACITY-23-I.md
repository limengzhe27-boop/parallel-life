# CHARACTER-CAPACITY-23-I · 长人物设定容量集成

2026-10-14，负责人：`/root/actor_save_diagnosis`；工作树：`character-capacity23`。

## 原因与处理

线上《渣男体验》草稿含六人，保存的内容为 64,807 / 65,536 UTF-8 字节。李之之已有第一维，刘胜男五维为空；在任一空维度加入约 200 个汉字就会触发 `content_budget`。此前的 `CHARACTER-SAVE-21` 已将整份草稿提高至 1 MiB，并同步扩大请求与数据库约束、明确保存失败提示。

本项收齐人物单维长度上限：作者原文五维各可保存至 16,384 字，导入、内容校验、人物补写上下文及缺失预览判定采用同一个上限。默认值整理保留超限原文供检查，而不静默裁剪。公开玩家预览仍不包含私有人物维度；AI 输入预算和可运行世界预算仍独立受限。
