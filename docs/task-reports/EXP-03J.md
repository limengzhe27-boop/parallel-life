# EXP-03J · 访谈照片改为正式附件引用

状态：待生产应用验收。负责人：codex-main-exp03j-20261002。基线：`78eaf01`。

## 问题与边界

此前访谈照片仅以 `[照片:/api/v1/assets/…]` 写进消息正文；界面据此猜测是否存在图片，无法从数据层区分“用户说了一句话”与“用户附了一张照片”。这也让后续记忆、删除、刷新恢复容易依赖字符串解析。本次只改现实侧访谈的一张照片附件，不扩大为世界/NPC 图片投递。

## 已实现

- 新消息用独立 `photoAssetId` 保存，正文只保存用户原话或短提示。服务端检查素材属于本账号、已加入现实档案、仍可读取且不是某个世界的照片；数据库外键、角色约束和触发器重复核验。
- 旧文本照片消息在迁移中只补素材引用，不改写历史正文；界面以保存的素材 ID 渲染，只有旧正文中的标记被剥去用于显示说明。普通用户输入或模型输出的标记不会自动成为图片。
- 照片发送的命令哈希包含素材 ID；纯文字和既有旧标记命令保持旧哈希，避免更新后重试变成幂等冲突。取消临时照片时同时检查新附件引用与旧标记。
- 向导只得到“用户附了照片”这一事实，不得到私有素材 ID，也不假称看到了图像内容。
