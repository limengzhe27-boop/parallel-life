## 需求与设计实现

本任务完成世界事项与备忘录系统的前端闭环体验（NOTES-WORLD-04）：
1. **备忘录四分区清晰展示**：
   - 『眼下要做的事』：聚焦近期事项（`near_term`）、待回复邀约与人物行动建议；
   - 『这段人生想做到的事』：聚焦活跃长期追求（`pursuit`）；
   - 『现在的处境』：聚焦人生起点身份设定与处境背景（`starting_context` / `opening_context`）；
   - 『此前记录』：折叠展示已达成、放弃或失效的历史事项；
   - 与独立可编辑的『我的便签』协同组合，系统事项完全只读，私人便签独立编辑互不污染。
2. **多源直达与行动快捷跳转**：
   - 系统事项行展示真实状态徽章（如“进行中”、“待回应”）与来源归属（“世界核实”、“你的讲述”、“人物建议”、“日程记录”）；
   - 提供直接快捷跳转按钮：直接前往地点现场（地图 `map`）、查看来源对话（微信 `wechat`）、查看日程（日历 `calendar`）；
   - 事项详情页完整展示来源事实、故事时间、客观核实依据及相关导航。
3. **手机首页关键事项卡**：
   - 首页优先展示当前活跃的近期事项或长期追求；
   - 明确显示卡片分区标签（“眼下要做的事” / “长期追求” / “人物建议” / “待办邀约”）、事项标题与状态/核实徽章；
   - 点击首页卡片直接进入备忘录该事项的专属只读详情页，支持返回；
   - 旧世界或无活跃事项时诚实回退至便签/选择或“还没有记录”，绝不伪造主线。
4. **锁屏因果通知联动**：
   - 仅基于服务端真实存在的 `world_matter`（状态为 `in_progress` 或 `blocked`）投递因果通知；
   - 包含状态标识与世界核实归属说明，点击直接解锁并跳转至对应备忘录事项；
   - 已完成/已放弃事项及旧世界不投递通知，绝不空喊任务完成。
5. **多端自适应与双端响应式**：
   - 手机窄屏 390×844、紧凑屏 390×500（自动隐藏卡片元信息防截断）与 PC 桌面端 1440×1000 均良好适配；
   - 路由状态与刷新保持无缝联动，权限隔离严格保持。
