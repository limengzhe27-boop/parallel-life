1. **冲突风险**：手机壳与五个应用（`src/features/phone/**`）正被并发执行者连续大改（最近三次提交 `c71183f`、`e77fcd9`、`aac0ad1` 全部是手机 UI 重构）。此刻修改共享壳、船坞与应用索引入口，很可能与其在途改动冲突。

3. 因此本轮只交付**可复用、零冲突**的客户端能力，把 UI 变成机械动作。
