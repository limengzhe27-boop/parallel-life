# EXP-03I · 放弃访谈照片时清理未使用素材

状态：待生产验收。负责人：codex-main-exp03i-20261002。基线：`597b441`。

## 问题与范围

EXP-03H 保留了照片消息的待发送状态以支持断流恢复，但用户主动选择「暂不发送」时，刚上传且尚未写入「我的」的私有素材仍留在存储中。直接使用原有照片删除接口又会解除已经存入档案的照片引用，不能用于待发送清理。

本次仅增加“未被使用的上传照片”清理动作：服务端按当前账号串行检查档案、已发送的本人照片消息和世界初始设定；凡是已经使用的素材拒绝清理。界面先读取已保存消息；若已发送，明确告知无法取消；若已入档，仅取消发送标记并保留照片；若未使用，调用清理动作。网络失败保持待发送标记和文字，可再次操作。现有普通删除接口行为不在本次修改范围。
