# D-24 L-03 导演控制面

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-24。状态：已完成并上线验证。

## 问题

用户此前对导演**没有任何指挥权**：不能给主题、不能调节奏、不能指定谁出场；也没有"重大改写先看影响"的路径。

## 改动

| 部分 | 内容 |
|---|---|
| 迁移 [0027_world_direction.sql](../db/migrations/0027_world_direction.sql) | `world_direction`（guidance ≤500、themes ≤5×40、pacing ∈ slow/normal/fast、focus_actor_ids ≤3，RLS 双角色） |
| [direction.ts](../src/modules/world/domain/direction.ts)（纯函数） | `normalizeDirection`：长度/数量/角色存在性校验；`beatsForPacing`：**slow=1、normal/fast=3**（节奏是硬上限，不是装饰）；`describeImpact`：**只描述影响不落库**（每拍次数、谁先出场、主题）；`directionLines`：把导演要求写进角色的舞台指示，且**只有被聚焦的角色**会被告知"多由你出场" |
| [direction-repository.ts](../src/modules/world/infrastructure/direction-repository.ts) | owner 作用域读写 brief；未设置时返回空 brief |
| [advance-world.ts](../src/modules/world/application/advance-world.ts) | 读取 brief：**节奏决定一次推进最多播几拍**（用户设置优先于调用方默认），聚焦角色进入选人（优先级：欠回应 > 未定约定 > 承诺 > **聚焦** > 沉默最久），brief 进入舞台指示 |
| `GET/POST /api/v1/worlds/:id/direction` | 读取与设置；`preview: true` 只返回影响不保存；**`move: 'past'` 被拒绝**（422，提示"历史不可改写：请建立分支，保留原人生"） |

## 验证

- `npm run verify`：**172 项单元测试 + 24 项真实库测试**通过。新增 `tests/world-direction.test.ts`（5 项）：节奏→拍数上限；brief 校验（超长/超量/未知角色/未知节奏一律拒绝，且会 trim）；**聚焦角色先于沉默规则、但未了结的事仍优先于聚焦**；`describeImpact` 不落库；导演要求到达角色且只有被聚焦者被告知出场。

- 构建通过。

## 遗留（诚实说明）

- **"重大改写的完整影响预览"只做到了可解释的量化描述**（每拍次数/先出场者/主题），还**没有**把"会改动哪些既有事件、需要建立哪条分支"做成对比视图；历史改写当前是**明确拒绝并指向分支**，而不是自动生成分支。
- 手机端**没有**导演控制界面（只有 API）；离线摘要展示与时间控件 UI 同样未接。
