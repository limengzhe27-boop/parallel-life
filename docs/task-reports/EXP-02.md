## 实际改动

- 聊天意图只在消息成功保存后处理，同时刷新资料与候选；刷新失败不重发已提交消息。否定、引用、假设与询问不触发创建意图。
- 删除自动选首个方向、隐式批准与自动带照片。先查看和选择方向，再复用 SeedConsent 确认资料；版本变更必须重新查看。
- 照片默认不选，确认页展示实际会带入的全部缩略图及数量。现接口仍为整组授权，逐张选择和持久 LifeDraft 属于 EXP-03。
- 创建失败引导查看原有进度，不通过重试重新推荐和批准另一条人生。
- 基础资料不再直接采纳模型字段。解析及两种写入路径采用明确本人陈述；毕业年份、朋友生日、否定称呼、假设城市、模型猜测不得覆盖资料。生日检查实际日期。这是有限表达提取，未命中留在对话，不是完整语义算法；其他事实/事件的可信校验待 EXP-03。
- 向导先倾听和了解关键经历，再讨论愿望；不每轮推销人生、不从星座推性格、不把照片标记当视觉输入、不声称未确认的世界已创建。
- 删除 SVG 模板生成实现，保留应用层适配端口。生产 Worker 未配置真实生成器时媒体请求为 failed/UNAVAILABLE，不新增相册资产、不标成功。用户真实上传仍保留。
- 撤下客户端拼接的朋友圈、点赞、评论与本地模拟发布，显示尚未开放；旧本地数据不删除，也不当作服务器记录。
- 保留历史素材并标明生成来源待核验；删除按标题猜测消息附件。可靠附件 ID 和真实媒体投递留给 EXP-03/NAR-03。
