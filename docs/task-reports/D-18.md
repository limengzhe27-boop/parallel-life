# D-18 Phase 1 收尾（世界侧）：回合认知写入记忆库

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-24。状态：已完成并上线验证。

## 改动

世界回合提交事务内（与事件、投影、outbox 同一事务）新增记忆写入，**不额外调用模型**：

| 写入 | 作用域 | 内容 | 来源 |
|---|---|---|---|
| 角色自己的印象 | `character`（scope=角色、branch=世界） | `belief.recorded` 的文本，kind=`belief`、sourceType=`agent_inference` | 该角色本轮的回复消息 id（真实 `world_messages` 行） |
| 这一轮发生的事 | `branch`（scope=世界、branch=世界） | 本轮最后一条回复（截断 400 字），kind=`episode`、sourceType=`world_event` | 本轮 `world_events` 行 id |

写入走 [memory-store.ts](../src/modules/memory/infrastructure/memory-store.ts) 的共享写入器：同作用域同类型下**重复表述合并来源**而非重复沉淀；来源经数据库触发器校验（`branch`/`character` 作用域必须指向真实世界；来源必须指向真实消息/事件），因此在事务内失败会与回合一起回滚，不会留下半条记忆。
