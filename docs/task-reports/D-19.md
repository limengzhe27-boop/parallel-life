# D-19 检索统一：角色回合真正读记忆

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-24。状态：已完成并上线验证。Phase 1 完成。

## 背景

并发执行者已把 [actor-context.ts](../src/modules/world/application/actor-context.ts) 的记忆过滤与预算写完（作用域检查、`profile` 私有隔离、遗忘来源屏蔽、`rankAndBudgetMemories`、3000 字预算），`ActorContext` 也已有 `retrievedMemories` 字段——但**没有任何调用方加载记忆**：`resolve-turn` 仍以空记忆构造上下文，角色实际什么都想不起来。本次把这条线接上。

## 改动

| 文件 | 改动 |
|---|---|
| [memory-store.ts](../src/modules/memory/infrastructure/memory-store.ts) | 新增 `loadActorMemories(sql, ownerId, {actorId, worldId})`：只取"该角色的 character 记录 + 该世界的 branch 记录"，`profile` 私有记录从不进入；`forgotten` 记录的来源进入 `blockedSources`（被遗忘的记忆不能通过它来源的那条消息复活）；`superseded` 记录不计入 |
| [resolve-turn.ts](../src/modules/world/application/resolve-turn.ts) | 新增可选端口 `memories(actorId)`；存在时把记录与屏蔽来源交给 `actorContext`，不存在时保持原行为（现有测试与调用方不受影响） |
| [services.ts](../src/server/services.ts) | 新增 `actorMemories(ownerId, actorId, worldId)`（owner 作用域事务） |
| [messages 路由](../src/app/api/v1/worlds/[id]/messages/route.ts) | 把加载器接进世界回合 |

## 验证

- `npm run verify`：**154 项单元测试 + 23 项真实库测试**通过。新增 `tests/integration/memory-retrieval.test.ts`：
  - 加载器只返回「甲自己的印象 + 本世界发生过的事」；
  - **乙的印象、别的人生的 episode、profile 私有记录都不返回**；
  - 被遗忘的记录不出现在结果里，且**其来源进入屏蔽集**；
  - 世界回合确实把这两条记忆交给了规划器（断言 `ActorContext.retrievedMemories`）。
- 无新增迁移。
