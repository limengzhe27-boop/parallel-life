# D-13 AUD-09 世界事实容量墙

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-24。状态：已完成并上线验证。

## 问题

`worlds.state` 有 256KB 硬 CHECK（`0001_foundation.sql`）。事实（`fact.established`、`belief.recorded`）只增不减，`compact()` 也一直保留全部 facts，每次回合又把全量快照写回 `worlds.state`。因此**聊得越久越接近上限，触顶后该世界的每一次提交都会违反 CHECK 并整事务回滚——世界永久无法继续**，而每次失败前还已经花了模型调用。

## 方案（投影 + 有界窗口 + 显式护栏）

|文件|改动|
|---|---|
|[db/migrations/0018_world_facts.sql](../db/migrations/0018_world_facts.sql)|新增 `world_facts` 投影表（id 主键、world_id/owner_id 外键、`ordinal`、document 大小约束）；RLS 双角色策略 + 最小授权；`(world_id, ordinal)` 索引；**并把既有世界快照里的事实回填进投影表**，使任何事实都不再依赖快照|
|[db/migrations/0019_world_facts_document_limit.sql](../db/migrations/0019_world_facts_document_limit.sql)|放宽单条 document 上限：一条事实最长 4000 个中文字符 ≈ 12KB，原来的 8000 字节会拒绝合法事实|
|[src/modules/world/domain/retention.ts](../src/modules/world/domain/retention.ts)|`retainFacts`：按**字符预算**（96K）而非条数保留——因为单条事实可达 4KB；始终保留世界构建时的 2 条基准事实（身份/情境），其余保留最新的|
|[src/modules/world/domain/reducer.ts](../src/modules/world/domain/reducer.ts)|应用事件后对事实做有界保留，内存窗口永不无限增长|
|[src/modules/world/infrastructure/postgres-world-repository.ts](../src/modules/world/infrastructure/postgres-world-repository.ts)|`compact` 不再把事实写进快照；`hydrate` 合并「构建快照基准事实 + 旧快照遗留事实 + 投影事实」并按 id 去重后做有界保留；`commit` 把本事件产生的事实按 `ordinal` 写入投影；快照仍超限时抛出**明确的领域错误**（而不是撞 CHECK 后整事务静默失败）；投影排序对 messages/facts 统一用 `ordinal`|

**取舍（如实记录）**：进入角色上下文的事实窗口是有界的（约 96K 字符）。被窗口挤出的旧事实**不会删除**，仍按世界存在 `world_facts` 里可查；只是不再参与角色每次的提示词。这是"容量与上下文预算"之间有意选择，而不是丢失数据。

## 验证

- `npm run check`：**110 项**单元测试通过（新增 `tests/world-retention.test.ts`：基准事实始终保留、保留最新的、丢弃最旧窗口项、默认预算下快照远低于硬上限）。
- `npm run test:db`：**16 项**真实库测试通过。新增 `tests/integration/world-facts.test.ts`：连续 16 轮、每轮 8 条 3000 字事实（≈390KB，远超 256KB 上限）——
  - 每一轮提交都成功（旧实现会在此处永久失败）；
  - 快照里 facts 为 `[]` 且总字节远低于 262144；
  - `world_facts` 保留全部 **128** 条事实（可查）；
  - 读回的世界版本正确、窗口有界、最新事实在窗口内、最旧的窗口项已不在、基准事实仍在。
- 迁移 0018/0019 已应用到**本地**与**生产 Supabase**（`pl_migrations` 19 条；回填后生产 `world_facts` 有 9 行）。
- **生产实测**（用户本人会话）：世界发一条消息 → `committed`，version 5 → 6，角色真实回复；生产库核对：该世界快照 **facts 为 0、1217 字节**，`world_facts` 有该世界的事实行，全库最大快照 5422 字节。
