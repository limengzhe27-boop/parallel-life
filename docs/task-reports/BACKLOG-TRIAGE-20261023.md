3. **只在三种情况下重新打开**：
   - 当前真实用户旅程再次复现同一故障；
   - 某个历史缺口被新任务明确依赖；
   - 负责人能给出真实 PG/浏览器反例。
4. 旧 `44-9~59` 中仍有参考价值的协议结论，已经转入 `44-161` 的恢复/展示/窗口子项；不另建第二套引擎。
