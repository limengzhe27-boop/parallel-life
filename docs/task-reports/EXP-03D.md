# EXP-03D 聊天到分支、可编辑的虚构身份

负责人：codex-main-exp03d。状态：待上线验收；EXP-03 整体仍进行中。

## 本批交付

- 用户已经与向导聊过时，分支空态显示最近的本人表述，并提供明确的「看看另一种可能」入口；用户点击后才发起 AI 推演。生成的方向在刷新后仍直接展开，避免刚生成却找不到。
- 草案增加可选的主角身份、发生地点、生活氛围。它们与故事正文一起保存、重开、确认，并写入不可变起点。空字段让模型自由推演；旧草案和旧起点保持可读。
- 世界创建只把用户确认过的虚构设定作为起点传给模型。明确指定的身份成为世界身份；明确指定的地点必须出现在开场地点，否则纠错重试并如实失败。不把虚构设定写入现实档案，也不自动带入私人资料。
