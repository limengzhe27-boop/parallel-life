# WRITER-UX-06 · 编剧工作台收拢

2026-10-13。用户反馈：无关字段太多、格式乱、不应要求每件事设置确定日期。根codex-main-source04-20261013唯一集成，Q工作台/review，B剧情/opening，根导入页面。沿用内容后台现有设计，不改协议、权限、运行时或数据库。

## 本轮方案

导入后先看实际故事稿，接着核对具体问题与原文，确认后填入可编辑草稿。默认后台先展示故事概览，再有人物、剧情发展和待确认问题。内部标识、精确运行参数和完整字段差异收进高级设置；问题不得因折叠而消失。

剧情阶段、候选节点的日期本来可选，可以依据前置阶段、事件发生或解决、玩家回应等既有条件推进。精确运行日期保留，但不强迫编剧为每个可能事件排日程。开场时钟、历史消息和已有邀约仍有真实协议约束；空缺与异常须明确提示并可编辑。本轮不引入自动排期或动态延时算法，不把时间说明文案当作运行能力。

## 导入页面

- 整理完成后收起上传/粘贴入口与原稿备份，仍可展开更换或重读。
- 实际整理稿排在来源核对之前，结构问题独立显露。
- 模型自述/补充和完整JSON差异折叠；模型自述不作为内容正确的证据。
- 两次核对勾选、草稿基线匹配、未知结果恢复、原稿变化清空旧结果和保存/试演/发布边界不变。
