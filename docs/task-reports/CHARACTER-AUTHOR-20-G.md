# CHARACTER-AUTHOR-20-G · 编导主动生成微信内容

状态：待集成人合入与线上验收。责任工作树：`character-author20-q`。本任务不调用真实模型、不操作数据库、不部署。

## 实现

- `scope=characters` 且编导显式选择 `socialFocus=history|moments|both` 时，服务端只围绕 `socialActorKey` 对应的唯一已有人物创作选中类别；人物姓名必须与唯一来源人物一致。找不到人物、同名歧义、来源不匹配时，在模型调用前拒绝。
- 模型输入只给所选人物及其已有微信记录。提示词将历史聊天和朋友圈分开，限制时间、知情范围及玩家过往承诺。纠错仍只在所选类别和人物范围内。
- 模型输出经服务端白名单后合并。其他人物、另一类别、已有聊天/动态、公开介绍、五维人设、世界和剧情均保留原稿；只有选中类别参与完整度检查。无 `socialFocus` 的旧人物文稿导入仍按既有逻辑运行。
- 私有角色试演只补实际手机运行所需的日常背景，不自动补历史聊天或朋友圈；即使模型偷偷提出记录，服务端也丢弃并保留作者原有记录。缺少微信内容不会因此触发纠错或阻止试演。
