## 问题与改动

线上合成验收第七次 NPC 输出把旧的 NPC 问句及旧消息来源放入 `replyAssessments`，而当前玩家只是在提出新的示意图请求。内核依原有来源与逐字引文规则拒绝了整轮；本项不改内核校验，也不把错误评估悄悄删除。

原生模型回复格式增加可选的当前输入上下文：仅玩家输入且本渠道、本会话有仍开放的问题时，评估的问题 ID 只能选这些已知问题，来源只能是本轮输入。短输入（不超过 1000 字）的引文必须是本轮原话全文，避免误引旧问题；长输入保留自由引文以免丢失复杂回答，但仍由内核验证其确为本轮原话的连续片段。非玩家输入或没有合法待答问题时，评估只能是空数组。旧回复解码与其他调用者兼容。
