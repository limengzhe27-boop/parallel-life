# LIB-02B2 · 私有设定试演与世界创建接线

2026-10-03；负责人 codex-main-lib02b2-20261003。状态：待验收。

目标：选定作者本人草稿的固定修订，默认零真实档案/照片带入，创建独立的私有试演世界。旧个人推荐Seed保持可读，新来源不得伪造推荐ID。模型生成开场必须保留作者角色与关系，不把可能结局写成已发生事实。此任务不开放他人设定目录、公开审核或UGC发布。

停止条件：按用户最新指示持续工作，监测剩余额度超过50%则安全收尾，不因02:00到达自动停止。


## 实现

新增显式setting_draft来源的Seed联合，旧无source个人Seed兼容；不伪造directionId/discoveryVersion。试演只查询本人Profile的身份外键ID，不读正文，现实资料/照片数组固定空。源修订通过0034复合外键与JSON来源一致性检查，完整不可变内容复制进玩家Seed。种子、建世界与任务在同事务内创建，重复命令恢复原世界，主动重开新命令获得独立世界。

模型只产出消息与便签，角色姓名、欲望、说话方式、与主角关系由服务端固定；模板ID映射短键后再映射世界UUID，开场第一条必须来自指定人物。NPC之间定向disclosure映射mayShare。普通人生与Seed列表不显示试演，专属列表可恢复。旧个人开场维持至少3人；试演支持2–7人。

## 验证

261项常规检查、46项真实数据库测试、build通过。新增真实库固定修订、并发幂等、跨用户、后改稿不改旧Seed、独立重开、入队失败回滚、完整快照与人物关系映射；Planner反例含个人两人拒绝、试演两人通过、七人/长ID/长姓名/28条关系保留、错误开场人物与模型重写角色被拒。

首次新集成测试在准备阶段使用不合法的identity自由文本，被现有资料保护拒绝；已改为合法合成兴趣，不降低资料边界，复跑通过。辅助指出全局两人下限可能放宽旧个人流程，已加旧路径显式人数校验和回归。

## 明确未完成

没有创作UI或公开目录/发布；试演是本人私有，不是多人。完整故事线只保存在Seed快照，开场只消费指定问题/代价/触发提示；后续导演的完整故事线生命周期未实现。possibleOutcomes不传开场模型，但不能据此保证模型永不在自由文字中编造结果。与主角关系的disclosure还没有独立运行语义（NPC间已映射）。未新增内容哈希，固定来源依赖不可变修订及快照。真实模型与公网仍待部署后验收。
