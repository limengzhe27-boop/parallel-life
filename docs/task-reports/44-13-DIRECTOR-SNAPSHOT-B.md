## Frozen API

`new PostgresDirectorSnapshotRepository(db).read(owner,{worldId,engineEpoch,worldVersion,candidates,blockers,focus?,now?}): Promise<DirectorSnapshot>`.

`readEvidence(owner,{worldId,engineEpoch,worldVersion,sourceIds,now?}): Promise<DirectorRawEvidence[]>` returns requested original records with sourceId/kind/knownByActorIds/worldVersion/sourceEventId/time provenance. It does not retrieve a summary or perform a model call. Unknown/unscoped sources fail; duplicates/empty requests are validated. Raw response budget is explicit, not truncation. `timeMeaning=as_of_story_time` for a current actor plan avoids pretending its read time was a newly observed plan start; other records retain source story time.

The class uses a dedicated short transaction helper: pool.connect → BEGIN ISOLATION LEVEL REPEATABLE READ READ ONLY → set_config owner → reads → COMMIT; catch ROLLBACK; finally release. It does **not** call SET TRANSACTION from PostgresDatabase.transaction callback, because that wrapper already selected set_config and a late isolation change fails on real PostgreSQL. No transaction surrounds a model call.

## Related evidence, not a full chat-history dump

Default observations are exact pending/candidate source/event associations, current facts, available positions, last known positions per observer/subject/kind, actor plans and referenced actual action results. Exact related event includes its original message/scene/group records. Unrelated old messages and authored history are omitted by default. There is no arbitrary latest50 or generated-summary fallback; adjacent-dialogue expansion is **zero** in this first builder, using exact business source association. Raw exact handles allow later explicit original-evidence retrieval.

Current source families include genesis:world, setting:world, event:id, fact:id, message:id/opening:id, appointment:id, group-message:id, scene-entry:id, plan:encodedActor:encodedPlan, action-result:id, actual-position:subject, position-knowledge:observer:event:subject:kind, calendar-response:event and accepted input IDs/input:id. Event IDs link back to successful same-owner commands; accepted input is explicitly labeled original player speech rather than execution proof. Canonical source evidence retains its original classification; an event receipt observation proves the event record exists, not that every embedded assertion is true. Raw event body is fetched only when the event is explicitly related/requested; unrelated event reads use compact provenance metadata.

- Canonical facts are fact; unknown legacy kinds/character beliefs stay belief. Explicit visibility and believedByActorId determine knownBy.
- Private message text stays speech and known only to that NPC. Old director stage cue masquerading as role=user stays plan, not a player statement. Authored history is labeled when explicitly requested.
- Group speech audience uses membership intervals **at the source version**, not current membership; an actor who later left can have known earlier speech.
- Scene entries use actual observableTo intersected with validated scene intervals. Narration is conservatively belief/description, not adjudication; adjudicated_result is result; actual time/place entry is fact. Plans/user attempts are never promoted to successful action.
- Actor plans are plan and known by their owner only. Actual result records are result with exact world/actor/event/version checks.
- Player AuthoritativePosition is global director truth with knownByActorIds=[], not automatic NPC knowledge. NPC actual position is its own evidence. ActorPositionKnowledge retains observer, sourceKind, occurredAt/learnedAt and possiblyStale; departure from an origin gives no destination. Director global access is **not** an NPC sharing grant. NPC input must remain typed nudge plus that candidate's original authorized sources; never forward snapshot/raw global records wholesale.

Budget uses frozen75 `DIRECTOR_SNAPSHOT_MAX_BYTES=1_000_000`, plus per-observation/schema worldSetting limits. Exceeding it explicitly fails; pending/actors are not dropped to fit. All actor state is retained for the protected snapshot; that does not mean every historical decision should be serialized into the eventual model prompt. Root owns model-facing whitelist/context policy. Source provenance metadata currently audits same-world event identity/continuity; large-world query/index and protected-snapshot budget scaling remain follow-up rather than an assertion of unlimited history performance.
