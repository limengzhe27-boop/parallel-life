## 一、导演能力：手机端真实控制面板（优先项 ①）

**问题**：手机里其实**已经有**一个"导演"面板，但它只是视觉稿——没有调用任何时钟/导演/推进能力，用户无法真正指挥或让时间走动。

**改动**：新增 [director-panel.tsx](../src/features/phone/director-panel.tsx)，并把手机壳 `renderPanel` 里的 `director` 分支内容替换为真实组件（仅一行接入）：

| 区域 | 能力 |
|---|---|
| 时间 | 显示**真实故事时间**、速度、暂停状态、上次离线摘要；按钮：暂停/继续、1×、2×、**让世界走一会儿**（回执显示"走了几件事 / 另有几拍合成摘要"，0 拍时如实说"这段时间没有该发生的事"） |
| 导演要求 | 自由文本要求（≤500）、主题（≤5，顿号分隔）、节奏（慢/正常/快）、**希望谁多出场**（复选框，来自真实角色列表，≤3） |
| 影响预览 | **先看影响**（不落库）：显示"接下来一次最多几件事、先出场谁、主题"；**应用**才生效 |
| 诚实提示 | "已经发生的事不会被改写；想换一种走法，请建立一个分支，原本的人生会保留。" |

**生产验证（如实分层）**：
- ✅ 已验证：面板可打开；显示**真实故事时间** `2026/9/24 13:59:46` 与 `1× 流逝中`（说明时钟读取接口真的接通，数据来自服务端时钟行）；按钮与表单齐全（暂停/1×/2×/让世界走一会儿；慢/正常/快；希望谁多出场：陈默/周惠/高远；先看影响/应用；历史不改写提示）。
- ⚠️ **未确证**：**点击"暂停"后 2.5 秒内面板未显示"已暂停/世界不动"**，也未出现"继续"按钮；未定位原因（可能是点击未命中该按钮、也可能是请求失败但提示未出现）。因此"暂停/倍速/推进的交互级验证"**不成立**，列为待验证（需要看清错误提示或直接观察服务端时钟行变化）。
