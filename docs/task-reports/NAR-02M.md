# NAR-02M · 后台每日有界唤醒

状态：已集成验收；负责人 codex-main-nar02m-20260929。基线 `47aa5df`，应用提交 `5e1b75e`。

目标：用户关闭页面后，服务端每日为少量已开始、未暂停且到期的世界运行现有导演回合。保留世界级锁、稳定命令 ID、unknown 不自动重试；另设定时任务专用权限和全局每日成本上限。

## 已实现

- Vercel 每日 04:00 UTC 定时访问受密钥保护的服务端入口。免费档可能在该小时内浮动，因此不是精确通知时刻；关闭页面后也不依赖浏览器计时器。
- 专用 `pl_scheduler` 数据库角色仅能调用受限的到期领取函数，不能读取私人世界表。函数只选择已有时钟、未暂停、20 小时未推进且无未决导演调用的世界；不扫描尚未打开过的世界。
- 同一 UTC 日期全局最多领取 2 个世界，数据库事务锁及每日唯一键阻止重复投递重复领取。每个世界本次最多推进一拍；回合继续使用已有的世界锁、稳定命令 ID、模型结果不确定时不自动重付。单个世界出错不阻断另一世界，但其未知尝试仍需人工恢复。
- 后台只负责生成并提交已有规则允许的消息。用户下次打开手机读取已保存的消息和日期；本次没有系统级推送通知。

## 限制与下一步

免费档每天只触发一次、每次最多 2 个世界，因此这是一轮成本受控的真实后台试运行，不是大规模持续运营或实时来信。Vercel 触发为尽力而为；漏触发时下一次按世界时钟补算。没有推送渠道，未读消息在用户重进手机时可见。超过当前额度的世界会排队到后续日期，需结合真实用户量、成本和体验数据扩容。长篇剧情状态、媒体任务执行和跨应用结果仍留 NAR-02/03。
