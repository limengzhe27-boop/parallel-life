# 眼下任务与手机入口

## 本地交付

- 首页从现有事项读取可信现场行动，核对地点、可达路径、关联约定状态与故事时间。任务卡打开事项详情，详情链接指向地图对应地点。
- R17 从已验证步骤推导玩家下一步。到场、口头自报、交出物品都不能替代独立接收记录。等待接收时事项仍在「人生记录」，完成后移入历史。既有受信规则按实绩解锁后续复核任务。
- 新版现场打开后复用现有事项投影。与当前事项相符的尝试走现有行动裁定和提交；无关对话继续走人物回合。校验步骤时按行动当时的版本回放约定，核对当前约定投影的事件来源。
- 「便签」收纳玩家私人文字。「人生记录」先显示任务与进展。「身份」显示存档人物资料，清除了硬编码随身物品和合成时间线。保留旧入口链接和记录来源。
- 沿用现有事项、队列、步骤和事件。仅在只读记录中增加 `scene_action` 类型及可选步骤标题，无 SQL 迁移。

## 验证

- 新版真实 PostgreSQL 12/12。官方剧本 R17 走生产分发器、到场、核对、交出、等待独立接收、完成、复核，以及私聊读取实际现场结果。模型输出受控；本轮没有做付费模型演绎验收。
- `npm run check` 4313/4313，构建通过。2026-11-06 切换 3218、队列和主动 worker 到同一构建，健康检查正常。
- 在原档「渣男体验」只读验证电脑与 390px 手机视口。首页显示与林白语商量见她父亲的剧情任务，三入口独立，便签页面只显示私有笔记。另一原有档案 `2fb97a4a` 的记录接口仍选择有据的青青请求。
- 另跑两份旧 PG 用例，上一构建同样失败。旧夹具涉及旧引擎和现场在场证据，本批新版生产入口专项独立通过。
- 公网健康探测 HTTP 402，本批未上线。

## 继续项

- 自定义世界新增调查或物品交付，需要该剧情已有可执行条件及验收证据。目前没有让导演临时生成任意道具或调查任务。原「渣男体验」本次未做实物签收。
- 旧现场记录兼容回归及真实模型抽样另验。现有实现对读取任务时尚未到约定时刻的事项不出卡片，纯时钟跨点而世界版本不变时，已有页面需刷新记录才展示。
