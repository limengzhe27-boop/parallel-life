## 问题

EXP-03G 已确保照片先入「我的」再发访谈消息，但页面在请求发消息之前就清除了待发送标记。若聊天请求失败或流中断，照片可能已在资料中，而访谈消息并未确认；刷新后没有照片重试入口，原本随照片发送的文字也可能丢失。历史消息中任何 `[照片:...]` 文本都被当作图片 URL，包括非本站地址。

## 本次范围与验收

- 待发送标记保存素材 ID 和原文字；资料入档后仍保留，直到确认访谈里有这张照片的本人消息。
- 每次恢复先读取已保存消息；已提交则清除标记，未提交则复用同一素材重试。断流或读取失败不宣布发送成功，不重复上传。
- 图片只对本人消息中合法的本站素材标记渲染；外部地址或不合法标记仍作普通文本。
- 运行 `npm run check`、`npm run build`，手机/电脑检查恢复状态；部署 Ready 后公网核对。此任务不改变数据库消息附件契约。
