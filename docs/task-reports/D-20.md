# D-20 Phase 2 时钟 + 导演骨架

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-24。状态：已完成并上线验证（骨架）。

## 问题

世界此前**没有时钟**：`state.time` 只在建世界时写入，之后永不推进；也没有任何角色会在用户不开口时行动。也就是说"人生"只在你盯着它的时候存在，这与 PRODUCT.md §7/§10 的"持续体验 / 1:1 时间 / 离线按经过时长补算"不符。

## 改动

| 部分 | 内容 |
|---|---|
| 迁移 [0026_world_clock.sql](../db/migrations/0026_world_clock.sql) | `world_clock`（story_now、speed、paused、last_tick_at、missed_beats、summary，RLS 双角色 + 最小授权）与 `world_beats`（每拍一行，`UNIQUE(world_id, command_id)` 保证一拍只播一次） |
| [clock.ts](../src/modules/world/domain/clock.ts)（纯函数） | `advanceClock`：默认 1:1、倍速相乘、暂停不动、倒退/零间隔不推进；**离线只播 ≤3 拍**，其余折进 `summary`（"世界照常运转了大约 N 小时"）并记 `missed_beats`；故事时间**始终追上现实**。`selectSpeaker`：选沉默最久的人、**不连续同一人**；`beatCue`：给角色的**舞台指示**（"用户没有开口"），绝不冒充用户说话。上限常量：`MAX_BEATS_PER_ADVANCE=3`、每拍 1 人 |
| [advance-world.ts](../src/modules/world/application/advance-world.ts) | 编排：读时钟 → 计算应播节拍 → 逐拍推进故事时间、选角色、记 beat（幂等）→ 走 **`resolveTurn` 同一条回合流水线**（因此自动获得回执/投影/outbox/记忆）→ 最后让故事时间追上现实。端口 `ClockStore` 定义在 application，实现放 infrastructure（边界合规） |
| [clock-repository.ts](../src/modules/world/infrastructure/clock-repository.ts) | owner 作用域读写时钟、写 `world_beats`、`setStoryTime`（`jsonb_set` 更新 `worlds.state.time`）；时钟缺失时从世界自身的故事时间惰性初始化 |
| `POST /api/v1/worlds/:id/advance` | 推进一条人生；返回 `played/folded/summary/storyNow/actors` |
| [services.ts](../src/server/services.ts) | 组装 `advanceWorld`（含角色记忆端口） |

**成本边界**：一次推进最多 3 次模型调用；暂停或未到一拍时 **0 次**（有测试锁住）。

## 验证

- `npm run verify`：**162 项单元测试 + 24 项真实库测试**通过。
  - 单元（`tests/world-clock.test.ts`，8 项）：暂停不动、1:1 每半小时一拍、倍速但拍数仍封顶、6 小时缺勤 → 播 3 拍 + 折 9 拍 + 摘要、故事时间追上现实、倒退/零间隔不推进、速度钳制、选人规则、舞台指示不冒充用户。
  - 真实库（`tests/integration/world-clock.test.ts`）：6 小时缺勤 → `played=3`、`folded=9`、世界版本 +3（每拍都是真实回合）、`world_beats` 3 行、`world.time` 移到 06:00、**不连续同一角色**；暂停后推进 `played=0` 且**没有模型调用**；无时间流逝也 `played=0`。
- 迁移 `0026` 已应用于本地与**生产 Supabase**（`pl_migrations` 26 条）。
- **生产实测**（用户本人会话，世界 `724aa514…`）：`POST /worlds/:id/advance` → 生产库出现 `world_clock` 行（`story_now=2026-09-24T05:59:46Z`、speed 1.00、未暂停）、`world_beats` **3** 行、世界 `time` 追到 `05:59:19Z`、**版本 7 → 10**（3 个真实回合）、世界消息从 11 增至 16。

## 遗留（诚实说明）

- 这是**骨架**：导演目前只做"时间推进 + 有界节拍 + 选人 + 舞台指示"，**还没有** L-03 的控制面（调整角色/主题/冲突/节奏）、也没有 agenda（谁欠你回应、哪些线未了结——记忆库的 `commitment/episode` 已具备原料）。
- 手机端**没有**暂停/倍速/跳下一事件的界面；目前只能通过 API 推进（`speed/paused` 已在时钟表里，接口未暴露写入口）。
- 离线"分块摘要"目前只写入 `world_clock.summary` 文本，尚未在手机里呈现，也没有把摘要写成记忆。
- 多人共享时钟（G-04）未动，但时钟按世界存储，具备共享基础。
