# PHONE-CHAT-NATIVE-01 · 手机聊天回归"像微信"

执行者 dsh-main-20260923；基线 `9c9ac43c`；已部署。

## 诉求（用户原话要点）
1. 点发送后消息立刻出现在聊天里，左侧一个小加载圈；成功后消失；不要下方"发送中/提交"等多余文案；
2. 去掉手机顶部「等待与休息 / 引擎与多A帧管理 / 世界持续运行…」等引擎内容——用户只是在体验世界；
3. 发送失败不要展示报错文字，只要微信式红色感叹号，点一下就重发；
4. 修"失败后一直失败"的问题（待验证/后续）。

## 本轮改动
- `world-phone-app.tsx`：**移除** `TimeExperienceControls` 挂载与 import（顶部"等待与休息/引擎与多A帧管理"不再出现）；
- `messages.tsx`：
  - 发送时**立即清空输入框**（乐观发送，不再出现"草稿还在 + 消息已发出"的割裂）；
  - "发送中…"文字改为轻量符号 `◌`；
  - 失败/待确认的整块文案与按钮替换为**一个红色 ❗**：点按即重试（`unknown` 时用浏览器确认框防止重复发送），不再出现"内容已保留/核对结果/再次尝试…"等字样；
  - 移除不再使用的 `confirmResend` 状态。

## 验证

- 手机/聊天相关测试 **128 项：127 通过、1 失败**；失败项为 `IMG-CHAT-01 ... Postgres integration`，原因是**本地数据库未启动**（`ECONNREFUSED`），与本轮改动无关。

## 遗留
