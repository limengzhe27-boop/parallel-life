# D-23 导演记忆化 + 世界时钟控制面

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-24。状态：已完成并上线验证。无新增迁移。

## 三件事

### 1. 记忆进 agenda（导演"记得"角色的承诺）
- [agenda.ts](../src/modules/world/domain/agenda.ts)：`buildAgenda(state, limit, memories)` 新增第三类线索 `commitment`——来自 `character` 作用域、`kind='commitment'`、`status='active'` 的记忆（"他之前答应过你：……"）。优先级：**欠回应 > 未定约定 > 角色承诺 > 沉默最久**。
- [memory-store.ts](../src/modules/memory/infrastructure/memory-store.ts)：新增 `loadWorldMemories(ownerId, worldId)`，一次取回本世界全部角色的 active 记忆 + 本世界 episode，供 agenda 使用。
- [advance-world.ts](../src/modules/world/application/advance-world.ts)：每拍用世界记忆构建 agenda；**离线摘要经 `rememberSummary` 端口写入 `branch` 作用域 `summary` 记忆**（由组装层实现，保持 application 不依赖 infrastructure）。

### 2. 世界时钟控制面（用户自己的时间权）
- 端口 `ClockStore.setClock`，仓储实现：只改 `paused` 与 `speed`（速度经 `clampSpeed` 钳制 0–60），**不动 `lastTickAt`**——已流逝的时间照算，既不丢时间也不凭空造时间。
- `GET /api/v1/worlds/:id/clock` 读取（故事时间/速度/暂停/被折叠节拍数/上次离线摘要）；`POST` 设置（`paused` 或 `speed` 至少一项，严格校验）。
- 暂停的世界：`advance` 播放 0 拍且**零模型调用**。

## 验证

- `npm run verify`：**167 项单元测试 + 24 项真实库测试**通过。
  - 新增单元用例：角色承诺进入 agenda 并驱动选人与舞台指示；`superseded` 的承诺不计入；**"欠回应"优先于"承诺"**。
  - 真实库扩展：`setClock` 暂停 → 推进 0 拍；设 1.5× → 读回速度 1.5 且暂停为 false；**控制变更本身不移动故事时间**；离线摘要经端口交给记忆写入器（`rememberSummary` 收到文本）；原有断言（3 拍上限、时间追上现实、暂停无调用）继续通过。
- 构建通过；无新增迁移。
