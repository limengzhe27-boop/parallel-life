基线 b95d21b8（含41-B）；root集成。仅新增 episode-question-links.ts、tests/episode-question-links41.test.ts、本报告。

## 已实现

`readEpisodeQuestionLinksInTransaction(sql, ownerId, state)` 返回派生 ActorAgentState。仅当前open、未绑定、private本人问题候选；按问题已有eventId/ordinal定向查询，没有全文扫描和关键词匹配。

认证同一world/owner/actor的 committed attempt → succeeded command → event → 原receipt。原snapshot只从完整 npc_agent_completion 读取，排除partial/superseded；不重新decode raw。校验原input身份/正文、sources、同轮proposal，并复用41-B `bindNpcFollowUpQuestion`。

关联还要求：原stateAfter question.id/sourceId/text/askedAt/channel/thread相同；proposal对应ordinal为唯一提问；message.received效果同ordinal且source一致；自动followup在原proposal和stateAfter相同（仅排除内核补上的revision）；当前同responsibility仍waiting/player、subject相同、历史来源仍保留。

只补当前question.responsibilityId，不动原source/askedAt/status，不生成决定、完成、消息、期限或新字段。无证明返回原state；prefix缺完整同事件证据继续未知。
