# NAR-02G · 人物给出的下一步

负责人：`codex-main-nar02g-20260928`。这是 NAR-02 中“选择获得人物承接”的一段，不等于完整剧情线或成就核验。

## 问题与处理

旧流程在导演发来一条消息后，就把选择标为“已承接”，但没有记录这条消息是否真的给出一个可行动的下一步。现在人物明确提出的帮忙、具体条件或处理方式，可以作为该选择的 `nextStep` 保存。它必须逐字出自同一回合、同一人物的已提交消息，包含来源消息、事件和版本；只能由导演针对该角色已知、尚未结算的选择写入。普通问候不产生下一步，人物提议也不会替用户答应或将事情标为完成。

模型可直接附带 `choice.next_step`。合成真实模型抽样显示，人物会说出具体提议却偶尔漏掉结构标记；因此增加保守的原话摘录，仅识别当轮人物消息里有明确行动表达的片段，仍经过同一运行时校验。旧世界没有 `nextStep` 时照常读取。

手机便签的“走过的路”把用户原话、人物后来提出的下一步和用户自述结果分别展示；新字段来自已保存事件，刷新后仍在，不是客户端生成的新剧情。没有证据时不显示下一步。

## 仍有限制

此记录是人物的提议，尚非真实履约或作品成果；自动摘录采取保守规则，某些自然说法可能留在消息里但不入“下一步”。导演仍在进入／回访时推进，未实现后台实时推送。完整目标、阻碍、兑现条件和跨应用结果仍属 NAR-02/03。
