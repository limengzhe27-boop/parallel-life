## 已实现

- POST/GET /api/v1/world-builds；GET /api/v1/worlds/:id。身份由既有签名会话提供，写入有同源/CSRF和限流，客户端不能指定所有者。
- 每份已确认 seed 对应一个 world-build 与 worldId。重复创建复用记录；通用任务队列保存 queued/running/failed/unknown/cancelled/succeeded，沿用租约、取消 fencing、明确重试，不用假百分比。
- 模型仅接收 seed 的 story、明确选入 facts、人物姓名/关系，不接收完整私人访谈、未选资料、照片内容/路径。验证3至5个唯一人物、开场消息引用、字段长度，服务端分配身份ID。
- 原子提交世界version=0、不可变开场快照、授权seed、生成内容与任务成功状态；迟到/已取消结果不能写入。读取世界时合并初始消息与后续事件投影，保留原回合契约。
- 如果卡片打开创建入口，已生成卡片进入 /worlds/:id。手机显示身份、人物、开场消息和私人便签；日历无自动接受的邀约；相册无假照片，壁纸明确为通用素材。人生管理可以返回如果切换已生成世界。
- D-03仍待媒体集成，D-05完整分阶段进度仍待后续，不将持续角色回合、照片、时间或导演标为完成。
