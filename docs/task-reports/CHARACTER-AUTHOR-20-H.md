# CHARACTER-AUTHOR-20-H · 编剧微信草稿编辑器

负责人：`author_ui20`。独立工作树：`/Users/limengzhe/.codex/worktrees/character-author20-h/人生剧本`。基线：`9632b0c`。只新增人物社交编辑器组件、样式、纯编辑模型与测试；公共契约、工作台和服务端由集成人接线。

## 交付范围

- 单输入框选择人物或主角发历史消息，可编辑和删除；“隔一段时间”在下一条消息保存时转为固定的一天间隔。已有原稿日期逐字保留；不能在开场前排下新消息时明确提示，不暗改原文。
- 三页微信形态：聊天、好友资料、TA 的朋友圈。好友资料仅编辑公开身份与公开介绍；私人人设、其他人物和手机内容不参与公开展示或写入。
- 朋友圈可编辑文字正文、可选发布日期并可查看、修改和删除草稿。无图素材合同，本组件明确提示图片未接入发布，未提供假上传或假生成。
- 开场尚未认识的人物不会生成过去聊天或玩家已可见的动态；试聊和项目 Agent 生成入口由集成人接到现有真实服务，编辑器没有假 AI 按钮。
