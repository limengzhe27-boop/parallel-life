# 首页「眼下任务」· 2026-11-06

## 实现

- 复用玩家记录和正式邀约。导演交接机会后，只有 NPC 通过原内核实际发出正式邀约、且记录能核验玩家可见的来源，才产生具体的玩家下一步。服务器按原 episode 执行证据标注「剧情建议」，不传导演内部文案。
- 首页显示一条，优先待决定的邀约，其次已确认赴约，再回退原有近期事项。记录里保留其他事项。任务详情给出玩家已经收到的相关话语，按钮打开同一条日历邀请。「先放着」只在本次手机会话隐藏该版本的首页卡片。接受、改期和不参加继续走既有日历流程。
- 接受后同一条记录切到赴约；改期重新待答；拒绝、错过或已记录赴约退出首页。普通聊天、暂缓和单纯到达地点不生成完成证据。玩家自行登记赴约仍是日程状态，不升级为世界核验结果。待答时段已过的任务退出首页，原邀请记录仍可查。
- P0 不增加任务表、定时器、通知或模型调用。导演交接的邀约通过已有动作证据产生任务；独立的泛化推荐及询问、交付等类型留待后续明确证据规则。
