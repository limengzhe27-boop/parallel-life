# D-07 从个人对话一键生成分支并进入手机

负责人 dsh-main-20260923（主登记目录，单人执行并自审）。2026-09-23。状态：待验收（功能已自测通过，视觉待用户实机确认）。

## 用户诉求与复现

用户报告："和 agent 对话后，他并不能直接生成对应的分支手机并进入"。要求在个人对话里就能生成分支并直接进入手机，且手机内可以真实对话。

**在真实浏览器复现了失败**（本地 3218，合成经历）：

1. 聊天后，聊天底部出现「开始这个分支 · 打开手机」。该入口**在没有任何已确认资料时就会出现**（`ProposalThread` 的 `ready` 传参未被使用）。
2. 点击后服务端确实执行了方向推演，但任务结果为 `failed / INVALID_AI_OUTPUT`；`discoveries` 记录 `directions: 0`。
3. 前端 `console.error` 后执行 `window.location.assign('/possibilities')`，**用户被静默跳走，看不到任何原因**。

根因两条：

- 方向推演要求"已确认资料（basis）或明确想法（brief）"，且模型在没有 basis 时容易返回不存在的 `sourceFactIds`，服务端按契约判为不合法输出（[discovery-planner.ts:32-64](../src/modules/discovery/infrastructure/discovery-planner.ts)，`input.basis.find` 找不到即 `UNKNOWN_SOURCE`）。
- 入口既没有前置条件，也没有失败提示：把"没有依据"和"模型输出不合格"两种不同情况都变成了同一个无解释的跳转。
