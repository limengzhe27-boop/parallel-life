## 失败与修正

1. 初次真实导演有“说稍后发日程却没有实际日程”及错误时间。补 JSON 模式、精确人物/地点/最早时间提示和有限私聊承接；校验仍要求真实邀请，不填造日程。
2. 旧来源只认初次导演回合，后续 NPC 真邀约无法连接地图/现场。新增 0049 独立后续来源；保留旧失败审计，新来源严格证明后才供地图/worker 使用。
3. 普通现场误用结构化步骤 observation 格式。分别提供普通与有证明步骤的提示，既有结构化步骤及 NPC 行动证据规则不放宽。
4. 一次角色回复过长。普通在场角色改为简短本人说话；后续样例缩短，但仍有自述情绪、固定口头禅及重复环境描写，不能称全部“去 AI 味”。
5. 第二次行动事项更新含协议外字段，严格拒绝。补明确两字段格式及负例测试；原失败保留，显式重试成功。没有通过丢字段或跳过校验掩盖失败。
6. 并入其他执行者地图/现场界面，移除无来源城市/天气及交通耗时倍率，保留实际地点、本地筛选/收藏、缩放和现场入口。另见 MAP-02-INTEGRATION-REVIEW。
