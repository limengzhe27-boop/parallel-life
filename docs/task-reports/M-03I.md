## 1. 架构与链路实现

完整闭环链路已落实：
$$\text{创作意图} \xrightarrow{} \text{配额与来源授权} \xrightarrow{} \text{Prompt Builder} \xrightarrow{} \text{供应商异步生成} \xrightarrow{} \text{二进制校验与私有存储} \xrightarrow{} \text{投递前复核} \xrightarrow{} \text{落库与 Outbox 完成}$$

### 核心模块职责划分

1. **`MediaPipelineService` (`src/modules/media/infrastructure/media-pipeline-service.ts`)**:
   - **配额校验**: 单世界硬顶额度（图片、视频、总成本预算）拦截；超额直接拒绝并抛出 `QUOTA_EXCEEDED`。
   - **角色视觉锚点与参考图解析**: 纯领域 `resolveCharacterReference` 校验；严禁 NPC 使用玩家肖像底模，缺失绑定时诚实降级为文字描写。
   - **版本化 Prompt 组装**: 图像采用 35mm 胶片光影摄影规范；视频采用 7 层画面结构与 4 层音频规范，并附带 `(no subtitles, no captions, no on-screen text)` 强制去字幕防烧录。
   - **供应商提交与轮询**: 调用 `MediaProviderAdapter`；超时或网络异常判定为 `STATUS_UNKNOWN`，严禁盲目自动 POST 重发。
   - **流与二进制 Magic Bytes 校验**: 检查 JPEG (`FF D8 FF`), PNG (`89 50 4E 47`), WebP (`RIFF...WEBP`), MP4 (`ftyp`) 签名，防止 CDN 错误页或 404 HTML 伪充素材。
   - **图像元数据解析**: 通过 `sharp` 校验宽高与真实有效性。
   - **私有存储**: 写入 `AssetStore`（私有路径），禁止直接使用供应商临时公网 URL。
   - **投递前状态复核**: 检查世界是否已注销/失效（`worldIsCancelled`）；若世界已失效，阻止投递（`approved: false`, `reason: 'WORLD_CANCELLED_LATE_DELIVERY_PREVENTED'`）。

2. **`createMediaPipelineHandler` (`src/modules/media/infrastructure/media-pipeline-handler.ts`)**:
   - **短事务读**: 获取媒体请求记录、当前世界资产计数以及世界存活状态。
   - **幂等重放保护**: 若请求已为 `ready` 且持有 `assetId`，不触发重复生成，直接补齐 outbox 并返回，防止重复扣费。
   - **未配置降级**: 若外部生成适配器未接入，诚实记录 `document.status = 'failed'`, `errorCode = 'UNAVAILABLE'`, 并完成 outbox job 状态为 `failed`（`UNAVAILABLE:media-adapter`）。
   - **两阶段提交 (Phase 3 Short Transaction)**:
     - 写入 `parallel_life.assets`（`origin = 'generated'`, `status = 'ready'`）；
     - 将最终投递决策 `deliveryDecision` 与 `assetId` 写入 `parallel_life.world_media_requests`；
     - 调用 `parallel_life.finish_outbox_job` 完成作业，保持两阶段严格一致。
