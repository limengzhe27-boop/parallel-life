# SOCIAL-FEED-PLAYER

- 玩家通过微信「发现 → 朋友圈」发布文字，可选择所有人物、指定人物或仅自己。朋友圈点赞沿用 `world.momentInteractions`。玩家可以点赞已保存的 NPC 私聊消息，使用独立的消息 ID，避免把消息冒充朋友圈动态。
- 写入沿用玩家权限入口、世界事务、事件、幂等回执和回放。发布不创建模型任务。普通私聊和已有 NPC 自主评估按权限读取最近 5 条运行动态，使用真实提交或分支初始快照证明。NPC 可以使用已有 `moment.interact`，玩家限阅动态要求与快照来源一致。作者预设动态继续按原规则展示给玩家。
- 权限依赖两个业务数据。动态的 `audienceActorIds` 缺省表示所有人物可见，空数组表示仅发帖者可见。消息点赞使用 `likedMessageIds`；两者均放在现有世界文档中。无新表、SQL 迁移、任务队列或定时器。
- 独立基线 2512cf8d，`npm run check` 4266/4266、`npm run build` 通过。真实 PostgreSQL 聚焦通过 11/11，含同一动态的授权 NPC 评论落库、未授权 NPC 猜 ID 被拒、玩家发帖/点赞持久化和重复命令去重。测试 NPC 使用受控输出。
- 独立本地生产构建在 3237。现有「渣男体验」仅核对读取，HTTP 200 和 23 条可见动态。另在隔离测试库走正式 HTTP 发布、原命令重试、点赞及刷新，均通过。未写入用户原档。未作真实模型自然互动、手机与 PC 浏览器验收、共享 3218 切换或公网发布。3218 由 STORY-CHAIN-55 同批串行集成。
