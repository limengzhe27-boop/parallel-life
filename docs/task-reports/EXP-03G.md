# EXP-03G · 聊天照片与「我的」资料保存一致性

状态：已完成生产验收。负责人：codex-main-exp03g-20261002。基线：`92574ac`。应用提交：`b5000f8`、`f7412a7`。

## 问题与范围

聊天里选照片后，当前界面先上传素材，再尝试把照片加入现实档案；第二步失败会被静默忽略，但照片消息仍会发送。这样用户看到「已分享」，而「我的」没有这张照片，后续草案也无法明确选择带入。此任务只修复这段真实资料写入与发送的顺序，不调整世界相册、生图或整个界面。

## 验收计划

- 成功时同一素材先出现在现实档案，再出现在访谈消息中；重复/并发资料版本变化不重复上传。
- 入档失败时不发送照片消息，不清空用户输入；保留已上传素材，允许就地重试。状态文案明确，不报假成功。
- 检查与构建通过，手机与 PC 核对上传/失败/恢复界面；部署后验证公网关键流程。

## 已实现与验证

- 上传后先把同一 asset ID 加入现实档案；只有服务端返回的档案确实包含该 ID 才发送照片消息。资料版本冲突时重新读取并重试一次，响应丢失但已保存时直接复用已有记录。
- 入档失败时保留用户输入和已上传素材 ID，显示可重试提示；刷新后从当前访客的 sessionStorage 找回待发送照片。此时不发送带照片的消息，也不再重复上传。入档成功后删除本地待发送标记。
- 待发送状态可选「暂不发送」，撤销本地待发送标记并恢复重新选图；这不会把未入档照片当作已分享。

## 限制

上传成功但用户主动放弃重试时，未引用的私有素材仍可能留在存储中；本任务没有新增素材清理命令。照片消息仍是旧的文本标记形式，正式消息附件契约及世界相册联动属于 EXP-03/NAR-03 后续范围。公网有效图片上传与入档失败注入尚未验收，不能以无效素材测试或本地模拟代替。
