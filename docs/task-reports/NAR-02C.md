# NAR-02C · 对话中的选择有下一步

负责人：`codex-main-nar02c-20260928`。本任务是 NAR-02 的一个有界交付；完整长期剧情结局与跨应用回报仍未完成。

## 交付

- NPC 对话模型可以提议一条 `choice.recorded`，只能引用本轮用户明确说出的行动原文。假设、转述、提问与导演指示不能写入；缺失或无效的可选选择提议会被忽略，不影响正常回复。模型只提议，最终领域校验再次执行。
- 选择与回复进入同一个世界事件和事务，保留用户原话、行动摘要、来源事件及版本。最近五条有界保存在世界快照；旧世界没有该字段仍能继续运行。角色只获知对自己说过的选择，不接收另一角色的选择或现实私人资料。
- 待推进的选择成为导演待办。下一个适当节拍由知情角色承接一次具体下一步，随后标记 `followed_up` 并停止重复提醒。角色回复不能把选择自动标成已执行、成功或失败。用户后续另作选择时，前一条仍未承接的同角色选择标为 `superseded`。

## 验证

- `npm run verify` 通过：全量常规检查与 33 项真实 PostgreSQL 测试。新增覆盖原文来源、假设/转述、角色可见性、回执、重启恢复和一次性导演承接。
- `npm run build` 通过。真实模型用合成纪录片场景抽样两轮：明确「我决定先把片头三分钟剪掉」产生 `choice.recorded` 并收到具体回复；「如果我决定……」只得到对话回复，没有产生选择记录。
- 生产 Supabase 29 项迁移校验和一致；本次无新增迁移。

## 边界

当前“承接”只表示角色对选择作了一次后续回应，**不表示主角真的完成了行动，也不表示剧情有了终局**。大目标、障碍证据、成功/失败/放弃的核实状态与照片/日历/便签的跨应用结果仍归 NAR-02/03。导演仍在用户进入或回访时推进，不是后台全天主动推送。旧世界继续兼容，但过去的消息不会被反向推断成选择。
