# EXP-03K · 现实资料去重避免误吞不同经历

状态：已完成，2026-10-02 集成验收。负责人：codex-main-exp03k-20261002。基线：`f957187`，应用提交：`828a8cf`。

## 问题

现有 `isSimilarText` 在没有逐字包含关系时，按汉字集合交集达到较短文本一半就判为重复。共享“我喜欢”“我想成为”等普通表达但关键对象不同的自述，可能被合并成一条，第二个资料项不会出现在“我的”，来源却错误挂到第一项。判重同时用于同轮提炼和后续现实档案写入。

## 本轮范围与验收

保持既有资料、来源与 API 不变；只收紧自动合并为可明确说明的相同表达或修饰性重复，不用泛化词面重叠猜两段语义等价。先加不同兴趣、愿望、经历和真实重复的反例，再跑真实 PostgreSQL 写入回合、全量检查、构建及生产验收。历史可能已误合并的数据不进行静默拆分，需要另做有来源的差异审查。

## 已实现与本地验证

- 删除“汉字交集达到较短文本一半”即合并的规则；现在只忽略标点、空格、开头自称和少数语气强调。语义改写即使可能等价，也先保留两条，避免无凭据地丢失后一句。
- 单元反例覆盖摄影/旅行、摄影师/音乐家、上海/北京大学，以及否定句和在原愿望上新增内容；“喜欢摄影”与“我还是很喜欢摄影”仍合并。
- 真实 PostgreSQL 访谈交替走流式和后台路径，验证两种兴趣、两种愿望、两段不同城市经历分别留存；真正重复的摄影兴趣只增添来源、不重复建条目。
- `npm run check` 254/254，`npm run test:db` 39/39，`npm run build` 通过。生产库发布前只读确认 31 项迁移齐全；本次无新迁移。
