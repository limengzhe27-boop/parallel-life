## 实际修改

- memoryHandler只解析任务和调用统一store，再由原queue.commit原子保存任务结果；删除derive/correct/forget的重复SQL与记录解码。
- insertMemory统一新增记录和来源引用；纠正和普通写入复用。
- 去重要求正文规范化相同、key相同、owner/scope/branch/character/kind/sourceType一致。避免同key新内容被忽略，也避免推测与用户确认混为一条。
- 相同正文合并source_ids与memory_source_refs，在同事务一致更新；已有来源引用缺项一并补全。
- 同key、同断言性质的新正文替代旧正文，旧记录status=superseded，原文和来源保留。不同性质的推测不替代用户纠正。
- 纠正/遗忘及已替代旧来源重放保留inactive状态，防止旧结论再次变active。
- 短事务内按owner/scope加现有PostgreSQL事务咨询锁，覆盖尚无记录时的并发去重；不创建锁表或跨模型持锁。来源合计超过现有32项契约时保留分记录，不截断来源。
- 纠正读取额外按branch/character过滤，避免复用人物id时跨世界替代。
