## Contract and decisions

`evaluateAgentActionEligibility(snapshot, proposal, action, context)` returns `{ status: ready | waiting | blocked, missing: { code, subjectId?, condition? }[] }`. Structural domain snapshot extends AgentValidationContext with required authorized viewState, redactedStateIds and sourceId observations. No application/framework/network/database dependency. Context has storyAt, optional authoritative actorPlaceId and optional **trustedResults** (including failed outcomes). Root confirmed this name and no plan.record exception. actorPlaceId must come from the actual kernel-authorized location of this NPC, never NPC belief, player speech, contactActorId or another actor location. Root owns world boundary/observability/director observation tracking; this helper adds no parallel path.

- All applicable visible plan triggers AND action preconditions gate execution; nextAction must select the action. Waiting plans can become eligible; blocked/terminal plans cannot execute. Removing action linkage from an existing plan cannot evade its gate. An unattached action remains valid when its own explicit conditions and active goal allow it.
- Use currentPlayerDecision with kernel responsibility revision. Earlier acceptance cannot authorize a changed request or override later refusal. No natural-language keywords, inferred consent, assumed timeout or invented deadline. Unrelated player text is not automatically consent or rejection.
- Only trusted real persisted/same-transaction action receipts satisfy dependencies/results. Never trust model/stored action status as result evidence. Receipt identity, registered visible action, evidence visibility, timestamp and worldVersion <= current+1 are checked. Same-transaction version is required for sequential execution within one commit. Failed dependencies block; explicit failed-result conditions can enable an alternative.
- Observation requires an actual authorized observation, not just source existence. Future/unavailable source bases block. Unknown/wrong location waits; only supplied spatial truth satisfies at_place. Source-backed time condition uses a real timestamp and does not invent one from text.
- Canonical state is read only to veto hidden state and terminal resurrection. Hidden linked plans return a generic hidden_state reason without exposing their trigger. No mutation of snapshot/proposal/action/context.
- Eligibility is **not** proposal schema/semantic validation, capability authorization or execution. Caller must validate proposals, authorize all supplied evidence and recheck final authoritative revision/time/permissions before commit. Collector must pass an empty delta for stored actions and the same authorized view. Kernel must use its validated proposal and final storyAt.
