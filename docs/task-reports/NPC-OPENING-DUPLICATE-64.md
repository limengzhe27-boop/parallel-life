# NPC-OPENING-DUPLICATE-64 同一个人把未被回复的话换种说法再发

## 现象

世界 `f0992c83`（渣男体验 v9）在开场 00:04–00:09 之后，补演在 00:10–00:23 又发了一轮：

| 人物 | 开场 | 补演 | 间隔 |
| --- | --- | --- | --- |
| 舒雅婷 | 00:08:15「那报酬我已经转好了，等你这边确认安排…」 | 00:10:18「报酬已经到账了…」、00:11:54「你这两天有确定具体哪天能过来带一下孩子吗」 | 2–4 分钟 |
| 欣欣 | 00:09:19「你妈…刚才还咳嗽得很厉害…」 | 00:10:57「妈妈咳嗽得很厉害…你现在能马上来吗」 | 1.6 分钟 |
| 李之之 | 00:06:24「今天来找我玩吗？拍了张好看的…」 | 00:10:31「自拍已经准备好…等你有空，我再发照片」 | 4 分钟 |

验收世界 `b14756f8`（v11，2026-11-05 20:22）里也复现了一次：舒雅婷 00:16:02 与 00:26:49 两条「转账 / 带孩子」安排，第二次由 `npc_episode_consideration`（origin=coordination）发出。

## 根因

两处，都会让同一个人把已经发出、玩家还没回的话再说一遍：

1. **补演选线只看“这条消息是不是我们俩最后一条”，不看它有多新。**
   `selectReturnThreads` 把 NPC 最后一条带承诺/问号的消息选成 `promise`/`question` 线程，即使它只发出 2 分钟。cue 让 NPC「给出具体进展」，可它没有新进展，只能换个说法把同一件事再问一遍。
2. **提交前没有兜底。**
   wake / coordination 的语句只要通过 schema 就落库，重复与否只靠提示词，模型并不遵守。

## 改动

- `src/modules/world/domain/return-briefing.ts`
  - 新增 `RETURN_BRIEFING_FOLLOW_UP_MIN_AGE_MS = 12 分钟`。
  - `promise` / `question` 线只有在玩家离开时这条消息已经存在 12 分钟以上才会被选中；刚发出的问话不再回访。
  - `owed_reply`（玩家说最后一句）和 `appointment` 不受影响。
- `src/modules/world/domain/repeat-guard.ts`（新增）
  - 只处理非玩家回合（`player` 例外，其余含 wake / coordination）。
  - 取本人最近 3 条已发消息；若玩家在那之后已经说话，直接放行。
  - 判重三条：同类型改写（内容字相似度 ≥0.35）、近似原文（≥0.6）、同上具体事项（两字词组重合 ≥2；类型不同时 ≥3），以及「自拍/照片准备好了，等你有空再发」这类延迟发送话术。
  - 快照里的 speech 观察没有 `storyAt`，因此时间窗缺失时改用观察顺序判断“玩家是否已回复”。
- `src/modules/world/infrastructure/npc-agent-kernel.ts`
  - `parse` 与 `commit` 都过一遍 `suppressRepeatedStatements`，被判定重复的语句直接丢弃；全部丢弃时就是安静（不再补一句）。

## 验证

- `npm run check` 4299/4299；`npm run build` 通过。
- 新增 `tests/repeat-guard.test.ts`（11 项）：用 f099 与 b14756f8 的真实重复对做正例，用「你吃了吗 / 今晚来酒吧」等做反例；玩家回合、已被回复、超过窗口、他人消息均不误伤。
- `tests/return-briefing.test.ts` 新增两项：离开前刚问的话不再被回访；已经沉淀的问题仍会回访。
- 真实数据回放：用 f099 补演窗口 `00:16:00→00:20:13`、只保留开场消息调用新的选线，返回 0 条线程（旧逻辑会选出舒雅婷、欣欣、李之之等并再次发问）。
- 真实快照回放：把 `b14756f8` 里李之之两次 wake/consideration 的原始快照 + 模型回复交给 `suppressRepeatedStatements`，00:32:17 与 00:32:58 两条自拍邀约都由「保留」变为「丢弃」。
- 真实模型回归：在 v11 新世界 `b14756f8` 上模拟 4 分钟离开（`last_present_at` 回拨 4 分钟、speed=1），补演只产生 1 条新消息（欣欣 00:30:14，全新内容），没有再出现同题重发。该世界已归档，历史保留。

## 剩余风险

- 判重是词面/事项级启发式，不是语义理解：完全换话题但同样在催的句子仍可能漏过；反过来，极少数同主题的新进展可能被压成安静。
- 选线 12 分钟门槛是产品取舍：刚开局就离开 4 分钟时，补演可能一条都不发（宁可安静，也不重发）。
- 生产未部署。验证跑在 3241；验证结束后 3218 已换成同一份构建（接手前该端口由 deepseek 手机验收的构建占用，重启会打断那边的进行中请求，已在交付说明里写明）。
- 判重只看本人最近 3 条、30 分钟内的发言；更早的旧话不会压新消息。
