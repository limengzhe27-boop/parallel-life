# AUTHORING-14-P2 · 人物页复用玩家真实手机

2026-10-13。执行者 author_people14，root集成。独立树从89055a1接续；人物试演组件、局部CSS、workbench/controller、新UI helper和专项测试，不改公共Phone/App、契约、数据库或模型服务。

## 实施

- 撤掉人物页自制聊天气泡、假朋友圈页及仿联系人导航。人物页手机只内嵌已有 `/workbench/trials/:id`，由现有 PublisherTrial→WorldPhoneApp→真实staff试演transport运行；界面、输入和NPC消息流程与玩家同一套组件。
- 不对姓名/同名角色猜ID。手机默认沿真实微信列表由作者选择联系人，查看资料/朋友圈和实际聊天。旁侧保留公开介绍文稿和五通用模块编辑，不用文稿模拟可聊天世界。
- 没有试演时提示保存后显式试演，未保存修改时不挂载手机并提供就近保存按钮；不自动创建试演、调用模型或推进动作。
- controller保存单个试演的workId/draftVersion/contentHash，真正试演响应必须确认同一已保存草稿和trial origin；错误/旧版本/旧hash拒展示。同版本再次打开复用已有存档，避免每次点击新建。
- inline人物手机与原drawer仅挂其中一个，关闭保留存档信息供再次显式打开；工作切换、保存成功、删除和注销清理可见挂载，旧存档不会当成另一份稿件手机。
- 人物页顶部试演同样采用inline入口，其他页顶部试演维持drawer。没有增加新服务契约、演员定向参数或iframe内部重绘；切人物不按姓名重建同一个手机。
