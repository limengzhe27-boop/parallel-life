# SOCIAL-WECHAT-56 微信式朋友圈发布

## 范围与实现

负责人 root-social-wechat；基线 dcfca52c。复用 SOCIAL-FEED-PLAYER 的 social.updated 事务、相册上传/素材鉴权、朋友圈投影；没有新增数据库表、列、任务或模型调用。

- 相机入口打开照片/文字选择；独立编辑页提供取消、发表、正文、至多9张照片、预览与移除。
- 选图复用现有相册和 uploadPhoto；上传完成立即可选，发布失败保留当前草稿和图片。
- 谁可以看使用公开/私密/部分可见独立页面，仍写已有 audienceActorIds；空选择不把选择器关掉。
- 动态“···”菜单提供赞/取消赞、评论；同一评论失败重试沿用 commandId，发表也沿用原幂等键。
- 纯图片帖子允许空正文；服务器核验图片属于当前世界可访问的已有相册，禁止任意URL/跨世界图片；最多9张且去重。
- 沿用不可变世界事件和现有 momentInteractions 保存评论/赞；取消赞按玩家与业务动态键移除投影。
- 已删除旧内嵌 composer 样式。修复共用手机按钮样式覆盖选图方块和权限选择控件；编辑中的照片保持小缩略图。
