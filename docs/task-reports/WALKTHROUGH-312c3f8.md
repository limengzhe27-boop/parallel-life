## 三、与预期不符 / 需要修的部分

### 1)【必须修】角色手机试演**没有常驻**——这才是"又变成纯填表"的直接原因

```tsx
// publisher-character-preview.tsx:92
{trial && !isDirty ? ( <iframe src={phoneTrialUrl(trial)} … /> ) : ( … )}
```
`isDirty` 一为真，iframe 就被移除。结果是：**提示条说"试演运行的是已保存版本"，但试演本身不显示了**——玩家看不到手机，只剩表单。

**建议改法（试演常驻 + 角标说明）**
```tsx
{trial ? (
  <div className={s.trialWrap}>
    <iframe src={phoneTrialUrl(trial)} title="手机试演" />
    {isDirty && <span className={s.staleBadge}>以已保存版本运行</span>}
  </div>
) : (
  <引导卡：还没有试演 → onStartTrial />
)}
```
对应的 `publisher-character-preview.module.css` 增加 `.trialWrap{position:relative}` 与 `.staleBadge{position:absolute;top:8px;right:8px;…}`。
