# NAR-02L · 人物间关系与转述边界

状态：已集成验收；负责人 codex-main-nar02l-20260929。基线 `dea51f2`，应用提交 `bc6a74f`。

目标：世界创建时保存定向人物关系，导演只可向有合理联系的 NPC 转述主角曾向说话人明确讲过的片段。接收者后续由既有一次性承接机制自然提及来源。旧世界不捏造关系；历史事件保持可重放。

范围：world-build 契约、生成、世界状态和转述校验及相关测试。无新迁移，沿用世界状态 JSON。

## 已实现

- 新世界的模型开场增加有方向的人物关系：谁可能向谁传话、两人如何相识。模型未提供关系时保持空，不从「都认识主角」推断他们彼此熟识。
- 导演只看到当前说话人可考虑传话的目标；模型仍可自行选择不转述。旧世界没有明示关系，新的跨人物转述默认关闭；原有已提交事件允许按原格式重放。
- 新转述事件携带新策略版本。最终提交前在数据库仓储检查版本，领域规则再次检查边的方向、许可、原始用户消息和保密话术。接收者只得到带来源的私有「听说」认知，由既有一次性后续回应机制承接。
- 关系说明限制为两个人如何认识，不允许写「你／主角」或疾病等未授权私人细节。第一次真实模型抽样确曾编造主角父亲复查信息，因此收紧提示与结构校验；第二次合成抽样生成 5 位人物、4 条有效关系，没有该类细节。
