# NAR-02H · 人物下一步与日历邀约同源

负责人：`codex-main-nar02h-20260928`。基线 `6b448b0`；属于 NAR-02 中跨应用后果的一段，不等于完整剧情线。

## 问题与处理

人物可能在主动来信里既提出具体下一步，也约定一个时间。过去便签只显示人物提议，日历独立显示邀约，用户看不出两者属于同一件事，也看不到确认或取消后的同步状态。

手机投影现在仅在**同一已提交世界事件、同一人物、且该回合恰好只有一条符合条件的邀约**时，将邀约链接到该选择的下一步。多条邀约或不同来源的邀约保持不关联，不按文字相似度猜测。链接只引用现有日历邀约，不创建新日程。日历状态是唯一事实来源；便签每次读取该状态，并显示“待你确认／已确认／已取消／你标记已赴约／你标记未赴约”。点按可打开对应的日历详情。没有下一步或邀约的旧世界照常显示。

开发样板加入明确标注的合成记录，只用于双端视觉检查，不进入生产用户数据。

## 限制与接续

关联依赖已提交的同回合邀约；不能把口头提议推断成日程，也不证明用户真实赴约。日历里的“赴约／未赴约”仍是用户自己标记。导演还没有完整的长期剧情目标、阻碍和兑现条件；自动后台唤醒与跨应用回报仍需 NAR-02/03 后续工作。
