## 2. 核心实现与架构保障

1. **多人生管理与选择 (Multi-life management)**:
   - 支持多人生卡片快速切换（如县城修车青年、江浙沪独生子、海边咖啡馆店主）。
   - 集成 `OfficialLivesView`（包含全部、精选、我的分类，以及原创封面、身份、开场钩子与存档标记）。
   - 包含分支提议与草案列表 `BranchList`。

2. **现实档案与平行轨迹对比 (Reality baseline vs. Parallel trajectories)**:
   - 严格遵循真实/虚构隔离原则：现实生活基线（真实身份、背景、原籍、分叉点）与平行世界轨迹（平行身份、如果假设、分叉抉择、核心代价、当前进度）清晰对比。
   - 标注隐私保护说明：真实访谈与隐私资料停留在现实档案层，绝密隔离不进入 NPC 对话。

3. **导演面板 (Director panel fixture)**:
   - 承接剧情调度设定：导演期望与引导语（guidance）、核心主题标签（themes）、剧情节奏（pacing: slow/normal/fast）以及希望多出场的人物焦点（focusActors）。
   - 提供“先看影响”预览计算（推进步长、重点角色与节奏）。
   - 提供“让世界走一会儿”单拍仿真推进，同步更新故事时间与阶段摘要。
   - 明确标注不可变历史约束：“已经发生的事不会被改写；想换一种走法，请建立一个分支，原本的人生会保留。”

4. **分支预览 (Branch preview)**:
   - 支持分支提议弹窗与详细展开：完整展示如果假设、身份设定、核心代价与开场情境。
   - 提供“进入体验”与准备手机操作入口。

5. **时间界面与时钟控制 (World clock & time interface)**:
   - **当前人生 / 日期清晰**:
     - 顶部常驻状态栏与时间卡片统一采用 `worldDateTimeLabel` 与 `worldWeekday` 进行 UTC+8 规范化中文展示（如 `2026-09-24 08:30 (星期四)`）。
     - 清晰指示当前人生名称（如 `县城修车青年`）与身份。
     - 实时反映时钟流逝状态：已暂停、1× 交谈中放缓、12× 日常推进。
   - 交互操作：暂停/继续时间切换、1×/2×/12× 倍速切换、快速时间推进（“稍等一会 (+15分)”、“等到赴约前 (+2小时)”、“休息到明早 (08:00)”）及离线分块摘要。
