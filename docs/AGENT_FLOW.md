# 后端 Agent 架构与全流程（展示版）

> 用途：给用户、领导与外部协作方说明「人生剧本」后端是怎么运转的。
> 事实来源：本项目代码（2026-09-24，`pl_migrations` 26 条）。**状态栏如实标注已实现/未实现**，不夸大。
> 同目录另有 [AGENT_ARCHITECTURE.md](AGENT_ARCHITECTURE.md)（工程契约版）与 [DEVELOPMENT.md](DEVELOPMENT.md)（唯一任务状态表）。

---

## 0. 先回答一个常见误解："是不是两个 Agent？"

**不是两个 Agent，而是"两个世界 + 一个导演层 + 一条共用流水线"。**

你的直觉抓住了最重要的那条线：**"和你聊天的 Agent"**（真实侧）与**"手机世界背后运转的 Agent"**（虚构侧）确实分属两个**互相隔离的世界**。但每一侧都**不是一个** Agent，而是一组分工明确的 Agent：

| 你的说法 | 实际结构 |
|---|---|
| "对话的 Agent" | 真实侧：**个人向导 Agent**（访谈提问+提炼）→ **人生探索 Agent**（生成分支）→ **世界创建 Agent**（建世界） |
| "手机世界背后的 Agent（楚门的世界导演）" | 虚构侧：**导演 Agent + 世界时钟**（决定这一刻发生什么/谁出场）+ **NPC 角色 Agent**（每个角色自己的回合）+ **记忆服务**（谁该记得什么） |
| — | 两侧共用：**运行时校验器**（AI 只提案，状态由事务写入）+ **执行层**（outbox → 任务 → 执行） |

关键规则：**真实访谈的私人资料永远不进入虚构世界**；角色只能知道"自己被允许知道的事"。

## 2. Agent 名册（6 个模型 Agent + 2 个引擎）

| # | Agent | 负责什么 | 谁触发 | 模型调用 | 现状 |
|---|---|---|---|---|---|
| 1 | 个人向导 | 和你聊，理解经历/兴趣/愿望/选择，问下一个问题 | 你在访谈说话（流式） | 1 次/发言 | ✅ |
| 2 | 人生探索 | 从你的资料生成多个「如果」分支，标明来源经历 | 你点"生成分支" | 1 次 | ✅ |
| 3 | 世界创建 | 生成身份、人物、关系、开场（消息/便签/日历） | 你采纳分支 | 1 次（含纠错重试） | ✅ |
| 4 | **导演** | 决定**这一刻该发生什么**：时间推进、谁出场、节奏 | 时钟推进（回来/倍速/主动推进） | **每拍 ≤1 次，一次推进 ≤3 拍** | ⚠️ 骨架已上线（缺控制面/agenda） |
| 5 | NPC 角色 | 一个角色的一轮：按人设回话 + 只记录自己的印象 | 你发消息；或导演点名 | 1 次/被点名角色 | ✅ |
| 6 | 记忆服务 | 提取/合并/纠正/遗忘/来源/作用域/按预算检索 | 访谈落库后、世界回合落库后、你手动纠正 | **0 次**（挂在已读原文的 Agent 上） | ✅ |
| 7 | **世界时钟（引擎）** | 1:1 时间、倍速、暂停、离线补算、节拍上限 | — | 不调模型 | ✅ |
| 8 | **校验器 + 执行层（引擎）** | 校验提案、事务落库（回执/事件/投影/outbox）、消费 outbox 执行任务 | 每次写入 / 每拍 | 不调模型 | ✅ |

## 3. 场景流程（给领导看的是这些）

### 3.1 用户进入 → 和向导聊天 → 信息沉淀进资料

```
用户输入一句话
   │
   ▼
[个人向导 Agent]  1 次模型调用
   ├─ 回复你（流式显示）
   ├─ 提炼 facts / events（结构化 JSON）
   └─ 确定性过滤：太短/问句/AI 自己的话/临时情绪/与基础资料重复 → 丢弃
   │
   ▼
[运行时校验 + 事务]
   ├─ profiles.document  ← 你的真实资料（自动写入，不需要逐条确认）
   └─ memory_records     ← profile 作用域记忆（来源=产生它的那条访谈消息）
   │
   ▼
噪音被拦下、同一句话重复出现时"合并来源"而不是再存一条
```

### 3.2 聊出结果 → 生成分支

```
你的资料（profiles）
   │
   ▼
[人生探索 Agent] 1 次模型调用  →  3–5 个「如果」分支（每个标明源自哪些经历）
   │
   ▼
你选一个 / 改假设 / 重新生成（提案状态，未采纳前不写世界）
```

### 3.3 采纳分支 → 创建世界（你进入某条人生）

```
[世界创建 Agent] 1 次模型调用
   ├─ 身份、时间地点、关键人物、关系
   ├─ 开场内容：消息 / 便签 / 日历
   └─ 写入"不可变基线"（world_initial_snapshots）+ 世界快照
   │
   ▼
手机界面出现：你的新人生（/worlds/:id）
```

### 3.4 在分支里和 NPC 发消息（NPC 如何运转）

```
你发消息
   │
   ▼
[意图路由]（确定性，不调模型）
   ├─ 普通闲聊 → 走角色回合
   ├─ 索图（"发张照片"）→ 同回合追加一条 media.requested（图片链入口）
   └─ 动作 → 走事件结算
   │
   ▼
[角色上下文裁剪]（角色只知道自己该知道的）
   ├─ 你以为的世界事实（可见范围内）
   ├─ 你和这个角色的最近对话 + 相关历史
   └─ 该角色的记忆：自己的印象 + 本世界发生过的事
      （私人访谈资料永不进入；被"遗忘"的记忆连同其来源一起屏蔽）
   │
   ▼
[NPC 角色 Agent] 1 次模型调用 → 提案：{ 回话，可选"自己的印象" }
   │
   ▼
[运行时校验] 角色不能替你说话、不能改现实档案、不能把印象写成世界事实
   │
   ▼
[事务提交] 回执 + 事件 + 投影（消息/日历） + outbox + 记忆（印象/本轮 episode）
   │
   ▼
手机界面按真实状态显示：发送中 / 已发送 / 失败可重试（失败不会假装成功）
```

### 3.5 索图 → 图片链路（谁说"没接入"就说"没接入"）

```
索图 → media.requested → outbox_jobs（与回合同一事务，绝不丢）
   │
   ▼
POST /outbox/drain（job id 即幂等键，重复派发不会重复排队）
   │
   ▼
media 任务 → [媒体执行]（配额/一致性守卫）
   ├─ 适配器已接入 → 生成到相册（并发执行者推进中：M-01/M-02/M-03）
   └─ 未接入 → 任务如实失败、请求保持 pending、**不生成假图**
```

### 3.6 你离开一段时间 → 世界自己运转（导演）

```
你回来（或主动"推进一点"）
   │
   ▼
[世界时钟（纯函数）]
   ├─ 故事时间追上现实（1:1；可倍速；可暂停）
   └─ 应播节拍 = 经过时长 / 每拍时长，**最多播 3 拍**，其余折成摘要
   │
   ▼
[导演] 逐拍：
   ├─ 选人：沉默最久者优先，不连续同一人（每拍 1 人）
   ├─ 给角色一段"舞台指示"（"用户没有开口，你可以主动做点什么"）
   │   —— 绝不冒充用户说话
   └─ 走与 3.4 完全相同的角色回合流水线（同一套校验/事务/投影/记忆）
   │
   ▼
手机上出现"你不在时发生的事"；一句摘要说明其余时间
```

### 3.7 说错了 → 纠正 / 遗忘

```
你说"这条不对" / "忘掉它"
   │
   ▼
POST /memory/records（correct / forget）—— 同步、单事务
   ├─ correct：旧记录 → superseded；按你的措辞写入 correction
   └─ forget ：记录 → forgotten（**不删除**），其来源一并屏蔽
   │
   ▼
之后 NPC 与导演都不再看到它，也不会通过它来源的那条消息"复活"
```

## 4. 你的资料如何运转（真实 ↔ 虚构 的边界）

| 数据 | 存放 | 谁可以读 | 用途 |
|---|---|---|---|
| 真实档案（facts / events / people） | `profiles.document` | 你、人生探索 Agent、世界创建 Agent | 生成分支、资料页 |
| 真实记忆（`profile` 作用域） | `memory_records` | 你（纠正/遗忘） | 沉淀与检索；**永不给世界角色** |
| 授权假设（被采纳的分支） | `approved_seeds` | 世界创建 Agent | 生成世界的唯一入口 |
| 世界事实（canonical/belief + 可见范围） | `world_facts` + 快照 | 该世界内被允许的角色 | 角色回话依据 |
| 角色认知（`character` 作用域） | `memory_records` | 该角色自己 | "他记得你什么" |
| 世界事件线（`branch` episode） | `memory_records` | 本世界的导演/角色 | 世界连续性与"未了结的线" |
| 真实照片 | 私有存储 `assets` | 只有你 | 资料页/相册；不进入世界 |

**一句话**：真实侧负责"你是谁"，虚构侧负责"如果那样，你的生活会怎样"；两侧共用同一套记忆机制与同一条流水线，但**数据不互通**。

---

## 5. 为什么这样设计（给领导的三句话）

1. **AI 只提提案，状态由事务写**：任何 Agent 都不能直接改数据，杜绝"AI 说了就算"和状态打架。
2. **每次调用都有价格，所以有硬上限**：一次推进 ≤3 拍、每拍 ≤1 人说话、离线不后台狂跑模型（只补算+摘要）；暂停时 0 次调用。
3. **不假装**：失败可见可重试、图片没接入就说没接入、unknown 结果绝不自动重付、没有的状态不显示（曾经硬编码的"在线"已去掉）。
