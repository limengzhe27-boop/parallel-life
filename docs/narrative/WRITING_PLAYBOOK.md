# 原创剧情单元写作手册

适用：内容作者、导演规划与 NPC 提示设计。它是项目内设计资料，不是已注册的模型 Skill，也不是可绕过运行时的指令。

玩家是体验主角：配角目标必须与玩家的生活产生联系，关键选择交回玩家，帮助不能变成配角代打通关。用户可以影响结果，而不是只读别人演完的剧情。

## 每个单元必须回答

1. 用户现在想做什么？为什么与这个身份有关？
2. 哪个已成立的事件允许这件事发生？谁知道哪些信息？
3. 对方自己想要什么，哪项限制有来源？
4. 用户至少有哪些不同走法？自由输入如何被接住？
5. 什么具体结果表示进展？何时算结束？
6. 哪个后续事件能承接它？何时应停，不再重复？

字段模板：名称／适用身份与偏好／触发条件与证据／当前目标／人物目标／可见范围／进入状态／可选行动与自由方案／成功、受阻、拒绝、延期结果／兑现条件／记录到手机哪里／结束与冷却条件。条件和结果由产品运行时验证，写作者不能直接声称数据已经改变。

## 可复用模式（全部为本项目原创示例）

| 模式 | 成立前提 | 用户能做什么 | 回报与收尾 |
|---|---|---|---|
| 被低估后争取机会 | 已有具体评价分歧，对方有评审或合作职责 | 展示证据、谈条件、换合作方、拒绝 | 获得一次明确机会或知道差距，不凭空立刻夺冠 |
| 两个好目标冲突 | 资源约束已经明确，双方都有合理诉求 | 缩小范围、换时间、找第三方案 | 保存取舍；不能所有目标无成本同时达成，也不强迫牺牲 |
| 一个小承诺兑现 | 角色确实答应过且有来源 | 等候、询问、协助、取消 | 交代进展或具体结果；兑现后不重新索取同样努力 |
| 意外的盟友 | 先前互动留下合作理由 | 接受、试探、保持距离 | 对方提供其能力范围内的帮助，不全能救场 |
| 信息差被澄清 | 双方拥有不同但有来源的信息 | 询问、查证、解释、暂不讨论 | 真相有迹可循；解决后的误会不能反复复活 |
| 计划受阻后绕路 | 已知现实限制触发，非临时凭空加码 | 改方法、找资源、延后或放弃 | 保留先前成果，形成新路，不惩罚自由输入 |
| 普通日子的小满足 | 用户偏好轻松或刚完成一件事 | 闲聊、分享、一起安排小事、离开 | 细节、理解与陪伴就是结果，不需要危机 |
| 选择之后再分岔 | 原线已有明确选择及不可逆后果 | 继续当前人生或主动探索另一条 | 新线保留原线历史，进入前讲清变化 |

## 一个导演人生例子

设定：小型影展愿意放映主角的短片；场地给的时长有限，制片合伙人希望保留最重要的情绪段落。人物都想把作品放出来，对“怎样最好”有分歧。

开场消息示意（不是固定生产回复）：“放映机会定下来了，不过只有十五分钟。你最舍不得哪一段？我先看能不能从别的地方腾。”

- 用户愿意剪辑：协商保留的内容，形成明确版本计划，不能立刻跳成获奖。
- 用户提出另一场放映：合伙人说明可联系的人和未知条件，允许第三种方案。
- 用户坚持完整版本：承认他的立场，说明当前场次限制，可暂不参加；不是羞辱失败。
- 用户解决时长问题：这个障碍真正结束，后续谈观众交流或放映准备，不又冒出“其实还差三分钟”。
- 用户说累了：自然收尾，未完成事项保留；不用“现在不回就错失人生”催促。

未来真实结果应落到活动、消息或作品；NAR-01仅改开场与角色回应策略，不能宣称上述所有后果已自动联动。

## 不合格信号

- 为悬念故意不回答已知问题；每条消息都以追问收尾。
- 人物没有理由地同意一切，或无论用户怎么做都不允许成功。
- 自由输入被拉回同一个选项，前一次努力无痕消失。
- 把真实隐私、照片、烦恼拿来制造羞辱或关系惩罚。
- 新角色突然解决全部困难；无伏笔背叛；成就只靠一句“你成功了”。
- 硬用同一高潮套路覆盖慢生活、家庭日常、浪漫或旅行。

每次评审先问：用户改变了什么？哪个结果已经兑现？这段现在能自然停下来吗？
