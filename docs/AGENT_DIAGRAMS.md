# Agent 流程图（展示用 · 纯 Mermaid）

> 用途：给领导与用户讲解「后端 Agent 做什么、信息怎么流、谁负责什么」。
> **刻意不含任何接口路径、数据库或技术栈细节**：这里只讲职责与信息流向。
> 图例：真实侧＝你是谁；虚构侧＝如果那样，你的生活会怎样。

---

## 图 1 · 总览：两个世界，一个底座

```mermaid
flowchart TD
  U["用户 = 唯一主角"]

  subgraph REAL["真实侧：你是谁"]
    G1["个人向导<br/>陪你聊 · 理解经历 · 提炼要点"]
    G2["人生探索<br/>把资料变成若干「如果」"]
    M1["个人记忆<br/>偏好 · 承诺 · 重要选择"]
  end

  subgraph FICT["虚构侧：如果那样，你的生活会怎样"]
    G3["世界创建<br/>身份 · 人物 · 关系 · 开场"]
    CLK["世界时钟<br/>时间流逝 · 暂停 · 加速 · 离线补算"]
    DIR["导演<br/>决定这一刻谁出场 · 发生什么"]
    NPC["角色<br/>只代表自己说话 · 只记自己的印象"]
    M2["世界记忆<br/>角色的印象 · 世界里发生的事"]
  end

  BASE["共用底座<br/>所有想法先作为提案提交，由统一校验与记录落定"]
  EXE["执行层<br/>把该做的事真正做掉（例如生成照片）"]

  U --> G1
  G1 --> M1
  G1 --> G2
  G2 --> G3
  G3 --> CLK
  CLK --> DIR
  DIR --> NPC
  NPC --> M2
  M2 --> DIR

  G1 --> BASE
  G2 --> BASE
  G3 --> BASE
  DIR --> BASE
  NPC --> BASE
  BASE --> EXE
  BASE --> M1
  BASE --> M2

  M1 -. "只以被采纳的假设形式进入" .-> G3
```

**一句话**：和你聊天的一套人负责「你是谁」；手机世界背后的一套人负责「如果你的选择成真」；两边共用同一个底座，但**私人信息不进入世界**。

## 图 2 · 每个 Agent 做什么（职责图）

```mermaid
mindmap
  root((后端 Agent))
    真实侧
      个人向导
        陪你聊天
        提炼经历与偏好
        提出下一个问题
      人生探索
        生成若干「如果」
        标明依据哪段经历
      资料与个人记忆
        事实 事件 人物
        可纠正 可遗忘
    虚构侧
      世界创建
        身份与人物关系
        开场内容
      世界时钟
        时间 1:1 流逝
        可暂停 可加速
        离开太久只补算少量
      导演
        决定这一刻发生什么
        选择谁出场
        维持整体一致
      角色
        只代表自己说话
        只记录自己的印象
      世界记忆
        角色的印象
        世界事件线
    共用底座
      先提案 再校验 后记录
      重复操作不产生重复结果
      失败看得见 可重试
```

**一句话**：只有「导演」负责全局节奏，其余角色只管自己那一份；没人可以直接改结果。

## 图 3 · 信息路径：你的一句话如何变成资料与记忆

```mermaid
sequenceDiagram
  participant U as 用户
  participant W as 个人向导
  participant R as 统一校验与记录
  participant P as 我的资料
  participant M as 个人记忆

  U->>W: 说一段经历
  W-->>U: 回应 + 提炼出的要点
  W->>R: 提交要点（提案）
  R->>R: 过滤寒暄 · 追问 · 临时情绪 · 重复
  R->>P: 写入我的资料
  R->>M: 写入记忆，并标注来自哪句话
  Note over P,M: 同样的说法再出现，只合并来源，不重复保存
```

**一句话**：你聊完就沉淀好了，不需要逐条确认；说重复了也不会存两遍。

## 图 4 · 从资料到分支，再到一段人生

```mermaid
flowchart LR
  P["我的资料"] --> D["人生探索"]
  D --> B["若干「如果」<br/>每个都标明依据"]
  B -->|"我选一个"| W["世界创建"]
  W --> L["我的一段人生（手机）"]
  B -.->|"改假设 / 重新生成"| D
  L -->|"过一段时间"| E["世界里发生新的事"]
  E --> L
```

**一句话**：分支来自你的真实经历；选中后才会建立世界。

## 图 5 · 你在世界里发消息时，发生了什么

```mermaid
sequenceDiagram
  participant U as 用户
  participant C as 可见范围裁剪
  participant N as 角色
  participant R as 统一校验与记录
  participant M as 世界记忆

  U->>C: 发消息
  Note over C: 私人资料不进入世界<br/>被遗忘的事连同来源一起隐藏
  C->>N: 只给这个角色该知道的
  N->>R: 提交言行（提案）
  R->>R: 不能替你说话 · 不能改现实档案 · 不能把印象当成事实
  R->>M: 记录角色的印象 + 这一轮世界发生了什么
  R-->>U: 真实状态：发送中 / 已发送 / 失败可重试
```

**一句话**：每个角色只知道他该知道的；回复是提案，经过校验才成立；失败绝不伪装成功。

## 图 6 · 导演的工作循环（让世界自己会走）

```mermaid
flowchart TD
  A["时间流逝"] --> B["世界时钟：算出现在该发生几件事"]
  B --> C["读我的要求：主题 · 节奏 · 希望谁出场"]
  C --> D["看还有哪些没完的事<br/>谁欠我回应 · 哪条约定没定 · 谁答应过我"]
  D --> E["选出场角色，并给他一段舞台指示"]
  E --> F["走同一套统一校验与记录"]
  F --> G["写入角色印象与世界事件"]
  G --> A
  B -.->|"我离开很久"| H["只补算少量事件，其余合成一段摘要"]
  H --> A
```

**一句话**：世界围绕「你还没了结的事」运转，而不是随机找人说话；离开再久也不会失控或超支。

## 图 7 · 时间：真实、可控、不失控

```mermaid
stateDiagram-v2
  [*] --> 正常流逝
  正常流逝 --> 暂停: 我按暂停
  暂停 --> 正常流逝: 我继续
  正常流逝 --> 加速: 我选择更快
  加速 --> 正常流逝: 回到 1:1
  正常流逝 --> 归来补算: 我离开很久后回来
  归来补算 --> 正常流逝: 最多补少量事件 + 一段摘要
  暂停 --> 静止: 世界不动 也不花费
  静止 --> 正常流逝: 我继续
```

**一句话**：默认与现实 1:1；暂停就是真的停；离开期间的空白用「少量事件 + 一段摘要」交代，而不是无限补算。

## 图 8 · 记忆的一生

```mermaid
flowchart LR
  A["写入<br/>不额外花费"] --> B["合并重复<br/>保留全部来源"]
  B --> C["按身份范围检索"]
  C --> D["用于角色言行与导演决策"]
  D --> E["我更正 / 我遗忘"]
  E --> C
  E -.->|"遗忘后，连来源一起隐藏"| C
```

**一句话**：记得住、改得掉、忘得干净。

## 图 9 · 隔离：一道只有单向的门

```mermaid
flowchart LR

    R2["我的真实照片"]
    R3["个人记忆"]
  end

  subgraph FICT["虚构侧（平行人生）"]
    F1["世界事实"]
    F2["角色的印象"]
    F3["世界事件线"]

  R3 -. "不进入" .-> F2
  R2 -. "不进入" .-> F3
```

**一句话**：世界只能拿到你授权的假设；真实资料与照片永远留在真实侧。

## 图 10 · 你指挥导演

```mermaid
flowchart TD
  U["我：换主题 / 放慢节奏 / 让某人多出场"] --> P["先看影响：接下来会发生什么变化"]
  P --> Q{"我确认吗"}
  Q -->|"确认"| A["生效，影响接下来发生的事"]
  Q -->|"不确认"| X["什么都不变"]
  U --> H["我想改写已经发生的事"]
  H --> B["系统不接受：保留原本的人生，改为建立分支"]
```

**一句话**：能指挥未来、能先看影响；历史不改写，改写就走分支。

## 图 11 · 为什么可以放心（三条底线）

```mermaid
flowchart LR
  A["隔离<br/>真实资料不进入虚构世界"] --> D["可信"]
  B["提案制<br/>想法必须经统一校验才成立"] --> D
  C["成本边界<br/>每次都有上限，暂停不花费"] --> D
```

**一句话**：可信不是靠提示词，而是靠结构与边界。
