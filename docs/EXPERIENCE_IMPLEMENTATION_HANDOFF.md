## 首批执行规则

- NPC群聊不是真人多人联机，现场不是微信群。
- 群发言限相关人物，常见1人、上限建议2人；群加入/退出与模型历史范围一致，私聊秘密不外泄。
- 现场文字项明确定型：旁白、当面对白、用户行动、裁定结果、媒体引用、时间地点。
- 返回手机仅切换界面，明确离场才改变在场状态；同一玩家/世界最多一个进行中的现场。
- 当前事项可受阻/完成/放弃，有事件依据；用户自述和世界实际裁定保持来源区别，不建立一句话万能奖励机制。
- 原图/头像展示与图生图分开。没有真实素材时，现场纯文字仍完整可用；不生成虚假的已完成图片任务。
- 首批现场时间不得由模型任意推进全世界。世界时刻沿用既有时钟服务；动作发生顺序额外记录，长时间行为在关键选择前停止。暂停世界仍允许查看，是否允许主动现场行动须在PLAY-01/SCENE-01接口审阅明确，不未经验证静默改暂停语义。
- 初始图可复用有授权的相应场景资产；成本策略以后实测，默认不逐轮/自动视频生图。
